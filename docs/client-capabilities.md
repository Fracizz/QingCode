# QingCode Next 电脑版与手机版能力对齐

> 2026-11-28 核对当前开发工作树。表中状态指客户端已有的入口和行为。发布与实机验收状态见[路线图](roadmap.md)，Codex、Claude、pi 的支持范围见 [Agent 能力矩阵](agent-capabilities.md)。

**已对齐**表示两端能完成同一件事，入口可以按鼠标、键盘或触屏调整。**有差异**表示同一能力在两端的行为或覆盖范围不同。**平台专属**用于桌面管理、网关授权、Android 系统集成等有明确平台边界的能力。

## 对话与 Agent

| 能力 | 电脑版 | 手机版 | 对齐状态 |
|---|---|---|---|
| 会话管理 | 新建、恢复、历史分页、重命名、归档与恢复 | 同左 | 已对齐 |
| 消息流 | 主聊与侧聊显示流式回复、工作过程、可展开的命令与工具结果、Agent 文件改动 | 同左，活动过程完成后可展开工具条目 | 已对齐。Agent 文件改动来自会话事件 |
| 下一条提示词建议 | Claude 主聊及持久分支侧聊的空草稿可点按或 Tab 填入 | Claude 会话可点按填入 | 已对齐。发送由用户确认 |
| 引用与评论 | 划词引用，添加评论后随下一条消息发送 | 划词或消息菜单引用，支持附加评论 | 已对齐 |
| 会话分支 | 整个会话、从已完成回复继续、将排队消息带到新分支 | 同左 | 已对齐。排队消息的分支在桌面侧边打开，在手机主对话打开 |
| 编辑重发 | Codex 原会话回退，Claude 和 pi 从轮次起始消息分支后重发 | 同左 | 已对齐。运行中暂停编辑入口 |
| 侧边对话 | 选区可发到临时侧聊，分支可在侧边打开 | 通过主对话引用或打开分支 | 侧边对话为桌面专属 |
| 永久删除会话、文件 checkpoint 回滚 | 按 Agent 能力提供 | 提供归档与恢复 | 平台专属。回滚改写目标机文件 |
| 运行中发送 | 引导、排队、打断后发送，支持编辑排队消息 | 同左。锁屏时符合条件的排队消息可交给电脑代发 | 已对齐发送方式，代发为手机场景 |
| 中断后继续 | 在原会话输入并发送「继续」 | 最近一轮已中断时可在提示右侧点「继续」，保留草稿 | 有差异。手机版提供快捷入口 |
| 审批、提问、MCP 请求 | 按 Agent 能力发给用户处理 | 同左 | 已对齐 Agent 交互 |
| Codex 异步提问 | 在消息流显示问题和选项正文 | 在消息流点选或填写，提交至当前会话，轮次结束后仍可回答 | 有差异。卡片依赖 Codex 消息里的结构化问题数据 |
| 模型、推理强度、访问模式 | 按 Agent 和目标能力提供 | 同左 | 已对齐 |
| 计划、子代理、后台任务 | 展示计划和子代理，支持查看及停止后台任务 | 同左 | 按 Agent 能力显示，同一子代理在两端使用相同的头像图形和配色 |
| 用量与压缩 | 账号额度、上下文用量、本轮或最近一轮工具调用摘要、手动压缩 | 同左，另提供 Codex 账号总用量 | 三种 Agent 的工具次数来自会话已加载的调用条目。Codex 额度和总用量需要 ChatGPT 账号时，按界面语言提示在运行 Codex 的设备上登录。数据和估算方式随 Agent 变化 |
| MCP 服务状态 | 查看当前会话的只读状态 | 同左，经网关读取 | 已对齐，需 Agent 和目标服务声明支持 |

## 输入与消息样式

| 能力 | 电脑版 | 手机版 | 对齐状态 |
|---|---|---|---|
| 斜杠菜单与技能发送 | 对话命令、可用 Agent 原生命令和技能。选中的技能作为 `skill` 输入发送 | 同左 | 已对齐。命令和技能列表随 Agent 及会话状态变化 |
| 手输技能名后发送 | 技能已在当前项目列表中时，完整的 `/技能名` 会拆成 `skill` 输入 | 同左 | 已对齐。未知名称和路径仍随正文发送 |
| 草稿中的技能 | `/技能名` 用普通文本显示 | `/技能名` 带圆角底色 | 有差异。桌面草稿高亮待定 |
| 已发送消息中的技能 | 圆角标签，相邻标签及正文用一个普通空格隔开 | 同左 | 已对齐。兼顾仅技能、连续技能和长技能名换行 |
| 图片和项目文件引用 | 支持选图、粘贴、拖放及 `@` 搜索项目文件 | 支持 Android 选图及 `@` 搜索项目文件 | 已对齐图片发送和项目内引用 |
| 本地文件作为附件上传 | 可将本地非图片文件上传到目标机后随消息引用 | 可引用目标项目中的已有文件 | 平台专属。手机项目文件接口保持只读 |

## 连接与工作区

| 能力 | 电脑版 | 手机版 | 对齐状态 |
|---|---|---|---|
| 目标连接与配置 | 本机、SSH、TLS 直连，管理目标配置和 SSH 主机指纹 | 经已配对电脑连接、断开和切换已有目标 | 新增目标和确认 SSH 主机指纹由电脑处理 |
| 手机配对 | 开放网关、提供配对信息、管理和撤销设备 | 扫码或粘贴导入，可保存多台电脑、编辑地址及重新配对 | 两端各自承担配对流程的一部分 |
| 项目管理 | 添加、管理项目和项目信任 | 浏览、选择和添加已连接目标下的项目 | 有差异。管理和信任入口在电脑 |
| 项目文件与搜索 | 文件树、定位当前文件、文件名和内容搜索、查看与编辑、差异视图。可从文件树或查看面板将项目文件路径加入当前对话草稿 | 只读浏览、文件名或相对路径搜索、预览及 Android 后台下载。下载通知随应用语言显示 | 有差异。手机文件权限按只读设计 |
| 项目 Git | 查看状态、历史和差异，支持暂存、提交、分支及远端操作 | 对话里可看 Agent 回传的文件改动 | Git 面板为桌面专属 |
| 终端 | 项目终端、多标签和断线接回 | 项目终端，电脑侧单独启用，按配对设备隔离 | 已提供终端，入口与授权有平台差异 |
| 运行配置 | 编辑、启动和停止运行配置 | 可使用已授权的项目终端 | 运行配置为桌面专属 |
| 定时任务 | 按项目管理 Codex、Claude、pi 的计划，运行记录可打开会话 | 可按普通会话查看已有结果 | 定时任务管理为桌面专属，调度在目标机执行。见 [T41](tasks/T41-scheduled-tasks.md) |
| 安装与更新 | Windows 安装包，桌面自动更新列在路线图延后项 | 应用内检查与安装指定的 HTTPS APK 或本地 APK | 平台专属 |
| 主题 | 深色、灰色、浅色 | 深色、灰色、浅色，另可跟随 Android 深色模式并在退出时恢复已选主题 | 手动主题已对齐，跟随 Android 为手机专属 |
| 进场与转场 | 启动页默认 1 秒淡出，主界面同步入场 | 启动页默认 1 秒淡出，手动整页切换默认 1 秒。自动恢复工作台和会话直接显示 | 启动时长已对齐。两端均支持减少动效 |

## 维护与验证

1. 改动一项能力时更新对应行，写清两端的实际入口、行为和前置条件。只有一端完成时，标明差异出在入口、行为还是权限。有任务卡时把链接放在该行。
2. 改共同语义时检查 [`packages/codex-client/src`](../packages/codex-client/src) 的共用逻辑。改交互或样式时查看桌面与手机的对应组件。例如技能要分别核对草稿、发送后的气泡和重开历史，包括连续标签和空格。
3. 改手机入口需要新 RPC 时，核对[手机网关](../apps/desktop/src/backend/mobile/gateway.ts)和对应测试。Agent 本身的支持条件变动时，同步更新 [Agent 能力矩阵](agent-capabilities.md)。
4. 功能和样式先做定向测试及相关包类型检查。手机 Web 构建、Android 真机和 Windows 验收按项目现有流程执行。 [开发与验收](../AGENTS.md#开发与验收) · [Android 测试](../apps/mobile/android/tests/README.md) · [Windows 验收](windows-acceptance.md)
