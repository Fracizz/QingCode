# 对比度、选择控件与文案规范（电脑版 + 手机版）

> 状态：v1（2026-11-26）。适用于 `apps/desktop/src/renderer/src/styles.css` 与 `apps/mobile/web/src/styles.css` 的 `@theme` token，以及所有组件里的颜色写法。
> 起因：手机强光下看不清对话输入框边界——输入框底 `#242424`、底栏 `#1f1f1f`、边框 `#2e2e2e`，三者两两对比度都只有 1.06–1.3:1；电脑版输入框（`#1f1f1f` 底 + `#3a3a3a` 边）同样偏弱，次要文字 `#6b6b6b` 在卡片上不到 3:1。

## 1. 硬性指标

对比度按 WCAG 2.x 相对亮度公式计算（见 §4 脚本）。“所在表面”指元素实际压在上面的那一层颜色，不是页面底色。

| 元素 | 最低对比度 | 依据 |
|---|---|---|
| 正文、标题、按钮文字（`qn-text` / `qn-prose`） | **7:1** | WCAG AAA 正文 |
| 次要文字（`qn-muted`）：副标题、时间、说明、图标按钮 | **4.5:1**，在它出现的**所有**表面上（含输入框、卡片、浮层） | WCAG AA 正文 |
| 辅助文字（`qn-dim`）：占位符、禁用、计数、kbd | **4:1**（在输入框底上）；不得承载必须读懂的信息 | 占位符要能在强光下读出 |
| **可输入控件外框**（输入框、对话输入框、搜索框、复选框）| **3:1**，与控件外侧表面相比 | WCAG 1.4.11 非文本对比 |
| 分隔线、卡片/芯片边框（`qn-border`） | **1.4:1** | 只做分组，不承担“这里能输入”的提示 |
| 控件次级边框（`qn-border-strong`）：描边按钮、分段控件 | **1.8:1** | — |
| 焦点态 | 外框改为 `accent`（或电脑版对话输入框的 `qn-outline-hover`），不得只靠底色变化 | 键盘与触屏都要看得出焦点 |

**判定口诀：能输入的东西必须有 3:1 的外框；只靠底色差（< 1.3:1）区分的层级在强光下等于不存在。**

## 2. Token（两端共用值）

| Token | 值 | 用途 | 实测对比度 |
|---|---|---|---|
| `qn-border` | `#383838` | 分隔线、卡片、芯片 | 1.5（`#181818` 上）/ 1.41（`#1f1f1f` 上） |
| `qn-border-strong` | `#4d4d4d` | 描边按钮、分段控件、浮层内边界 | 2.1 / 1.95 |
| `qn-outline` | `#6b6b6b` | **可输入控件外框** | 3.33（`#181818`）/ 3.09（`#1f1f1f`） |
| `qn-outline-hover` | `#858585` | 电脑版输入框悬停、对话输入框聚焦 | — |
| `qn-composer` | 电脑 `#262626` / 手机 `#2a2a2a` | 对话输入框底色，比周围亮一档并带 1px 顶部高光与投影 | — |
| `qn-muted` | `#a0a0a0` | 次要文字 | 5.8（`#262626`）/ 5.05（`#303030`） |
| `qn-dim` | `#8a8a8a` | 占位符、辅助文字 | 4.38（`#262626`）/ 4.16（`#2a2a2a`）/ 5.1（`#181818`） |
| `qn-raised`（手机） | `#303030` | 用户气泡、禁用发送键 | 1.35（`#181818` 上） |

旧值对照：`border #2a2a2a/#2e2e2e → #383838`，`border-strong #3a3a3a → #4d4d4d`，`muted #939393 → #a0a0a0`，`dim #6b6b6b → #8a8a8a`（旧 dim 值现在作为 `outline`）。

## 3. 写法约定

1. **不写裸色值**。新增颜色先进 `@theme`，组件里用 token；需要更亮的局部变体时像 `.qn-surface-float` 那样在子树里重定向 token。
2. **输入类控件一律用 `qn-outline` 外框**：电脑版 `.qn-input`、`Checkbox`、`Composer` 卡片；手机版 `.qn-input / .qn-textarea / .qn-search / .qn-composer`。不要把输入框边框写成 `qn-border` / `qn-border-strong`。
3. **对话输入框**：`qn-composer` 底 + `qn-outline` 外框 + `inset 0 1px 0` 顶部高光 + 投影；聚焦时电脑版外框 → `qn-outline-hover`，手机版外框 → 70% 品牌青。
4. **占位符**统一 `qn-dim`（手机版全局 `::placeholder`，电脑版 `placeholder:text-qn-dim`），不依赖浏览器/WebView 默认灰。
5. **层级不靠底色差单独表达**：相邻表面明暗差 < 1.3:1 时，必须再配边框或投影其中之一。
6. **改色前后都跑 §4 的脚本**，把新的组合补进 §2 表格。手机版还要在亮度拉满的真机上看一眼对话页输入框、搜索框、底部按钮。

## 4. 选择控件形态

| 场景 | 控件 | 形状 |
|---|---|---|
| 固定 2–7 项的单选（推理强度、速度 标准/快速、会话范围 本项目/全部） | **分段控件**：手机 `.qn-segment`（按钮带 `role="radio" aria-checked` 或 `aria-pressed`），电脑版 `SegmentedControl` / 模型选择器内的分段按钮 | 等宽网格；外框 12px、内项 8px 同心圆角；选中项品牌色底 + 描边 + 加粗 |
| 开关型选项 | 分段控件的“关 / 开”两项，或 `Checkbox`；**不用**单个可按下的胶囊 | 同上 |
| 横向滚动的筛选、标签、已选项 | 胶囊芯片 `.qn-chip`（`rounded-full`） | 高度 ≤ 32px，文字单行 |
| 带说明的列表选项（模型） | 整行卡片 `qn-row` + `rounded-xl` | 说明文字可换行（`whitespace-normal` + `overflow-wrap:anywhere`），不得溢出到右侧勾选图标 |

- **胶囊只用于矮元素**：当触控规范把按钮撑到 ≥ 40px 时，`rounded-full` 会变成竖椭圆（旧版推理强度就是这样），必须换成分段控件或 8–12px 圆角。
- 当前选项的说明放在分段控件下方一行 `.qn-hint`（手机）或 `Tip`（电脑），不塞进按钮里。

## 5. 文案

- 界面上的模型说明、推理强度说明一律中文：服务端 `model/list` 只给英文，统一用 `@qn/codex-client` 的 `localizeModelDescription`、`effortHint`（`packages/codex-client/src/modelText.ts`，两端共用；新增译文只改这一处）。
- 推理强度档位名用 `effortLabel`：低 / 中 / 高 / 超高 / 极高 / 极致。

## 6. 校验脚本

```js
// node contrast.mjs '#181818:#6b6b6b' '#2a2a2a:#8a8a8a'
const L = (h) => {
  const c = [1, 3, 5].map((i) => parseInt(h.slice(i, i + 2), 16) / 255)
    .map((v) => (v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4))
  return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2]
}
for (const pair of process.argv.slice(2)) {
  const [a, b] = pair.split(':').map(L)
  console.log(pair, ((Math.max(a, b) + 0.05) / (Math.min(a, b) + 0.05)).toFixed(2))
}
```
