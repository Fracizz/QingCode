# QingCode Next 桌面端 UI 设计方案 v1（外壳骨架）

> 状态：v1（2026-11-25）。范围：桌面端外壳（窗口、标题栏、侧栏、主区、状态栏、进场页）。协议与业务以 `docs/mvp.md` 为准，本文只管界面结构与视觉语言。

## 1. 借鉴来源与取舍

| 来源 | 借鉴 | 不照搬 |
|---|---|---|
| **t3code** | 侧栏"项目 → 会话"两级树，会话直接挂在项目下；居中窄栏消息流；圆角大输入框，左下角 Agent/上下文标识、右下角圆形发送按钮；空态只给一个主操作 | 没有"目标（机器）"概念，这层由我们补上 |
| **Orca** | 底部状态栏承载运行信息（连接、Agent 进程、额度）；目标/仓库状态点；自绘标题栏 | 终端/工作树为中心的多面板布局（MVP 不做终端） |
| **Codex 桌面版** | 石墨灰逐级分层（标题栏 < 内容 < 侧栏 < 浮层），靠细线分割；标题栏显示当前会话；输入框占位符「和 Codex 一起工作」 | — |
| **旧版 QingCode**（`D:\code\qingcode\DESIGN.md`） | 品牌青 `#4ecdb5` 只表达"当前上下文"（青轨 Qing Rail），功能强调用蓝；圆角三档 4/6/8；进场页（内联 Logo + 青色进度条，最短展示后淡出） | 标题栏项目 chip、活动栏等 IDE 结构 |

## 2. 原则

1. **对话优先**：横向空间留给消息流。旧版"目标列 + 项目/会话列 + 对话"三栏合并为"侧栏 + 主区"两栏。
2. **一处一事**：同一错误只在最相关的位置出现一次（连接失败在目标切换器，Codex 打开失败在主区横幅）。
3. **一个主操作**：每屏只有一个实心主按钮；空态按"未连接 → 没项目 → 新建会话"给出唯一的下一步。
4. **青色克制**：`brand` 青只用于 Logo、当前会话的青轨、展开的项目图标、运行中指示；按钮与焦点用 `accent` 蓝。

## 4. 窗口外观

- **去掉系统标题栏与菜单栏**：`titleBarStyle: 'hidden'` + `titleBarOverlay`（Windows 保留系统最小化/最大化/关闭按钮，Win11 悬停最大化仍有贴靠布局）；`Menu.setApplicationMenu(null)`（仅非 macOS，macOS 的 Cmd+C/V/Q 依赖菜单）。
- 系统按钮区颜色 `#141414` / 图标 `#a1a1aa`、高度 38，与 `styles.css` 的 `--color-qn-chrome` 及标题栏高度一致，改一处必须同步另一处。
- 标题栏整条 `-webkit-app-region: drag`，按钮/输入等自动 `no-drag`（`.qn-drag button …`）；模态遮罩加 `qn-no-drag`，打开弹窗时不能拖窗。
- 右侧占位宽度用 Window Controls Overlay 的 `env(titlebar-area-*)` 精确计算，不支持时按 138px（3×46）估算；macOS 左侧留 76px 给红绿灯。
- 去掉菜单后开发态补回 `F12 / Ctrl+Shift+I`（DevTools）与 `Ctrl+R / F5`（刷新）。
- 窗口 `show:false`，`ready-to-show`（即进场页首帧）后再显示，3 秒兜底，避免白屏闪烁。

## 5. 进场页

静态写在 `index.html`（内联样式，CSP 不允许内联脚本），HTML 解析后立即可见；React 只负责更新状态文字与淡出（`lib/splash.ts`、`hooks/useBootSplash.ts`）。

| 时间 | 动画 |
|---|---|
| 0–620ms | 青色图标底块缩放旋入（轻微回弹），背后青色光晕呼吸、细网格淡入 |
| 220–700ms | 尖括号从左滑入 |
| 400–820ms | 白色"光标"横条从左展开，之后以 1.1s 周期闪烁 |
| 300–1100ms | 标题「QingCode Next」→ 副标题 → 进度条 → 状态文字依次上浮 |
| 就绪后 | 进度条由滑动变为填满，状态「准备就绪」停留 220ms → 整页淡出 + 轻微放大 + 模糊（360ms）；主界面标题栏 → 侧栏 → 主区 → 状态栏错峰 70ms 上浮入场 |

- 阶段文字：正在启动 → 正在连接后台服务…（等 MessagePort）→ 正在加载连接与项目…（等 `targets.list`）→ 准备就绪。
- 最短展示 1200ms（入场动画完整播完），最长 8s 兜底（后台卡住也进入主界面并显示错误）；`prefers-reduced-motion` 时无动画、最短 300ms；`--smoke` 不等待。
- 底部显示版本号（`qn.version()`）。整页可拖动窗口。

## 6. 视觉语言

### 色彩（`styles.css` `@theme`）

| Token | 值 | 用途 |
|---|---|---|
| `qn-chrome` | `#141414` | 标题栏、状态栏、进场页、窗口底色 |
| `qn-bg` | `#181818` | 主对话区 |
| `qn-sidebar` | `#1b1b1b` | 侧栏 |
| `qn-panel` | `#1f1f1f` | 卡片、输入框、弹窗 |
| `qn-elevated` | `#242424` | 下拉、菜单、Toast |
| `qn-hover` / `qn-active` | `#262626` / `#2c2c2c` | 悬停 / 选中 |
| `qn-border` / `qn-border-strong` | `#2a2a2a` / `#3a3a3a` | 分隔线 / 控件与浮层边界 |
| `qn-text` / `qn-muted` / `qn-dim` | `#e6e6e6` / `#939393` / `#6b6b6b` | 正文 / 次要 / 辅助 |
| `qn-brand` | `#4ecdb5` | 青轨、Logo、当前上下文、运行中 |
| `qn-accent` | `#4f8cff` | 主按钮、焦点、链接 |
| `qn-ok` / `qn-warn` / `qn-danger` | `#6fcf8f` / `#e2b55d` / `#ff6b63` | 已就绪 / 连接中·待审批 / 错误 |

### 尺寸

- 圆角：4px 行内小按钮与徽标；6px 按钮、输入、列表行；8px 菜单、弹窗、卡片；输入框卡片 16px；圆形只用于状态点与圆形图标按钮。
- 图标：12（徽标/状态栏）、13–14（列表/工具条）、16（标题与主按钮）。
- 字号：正文 13–14px，辅助 11–12px，路径用等宽（`--font-mono`）。

### 状态语义（`lib/targetStatus.ts` 统一）

未连接 灰点 · 连接中/部署中 琥珀点闪烁 · 已就绪 绿点 · 连接失败 红点。切换器、面包屑、状态栏共用同一套颜色与文案。

## 7. 交互与快捷键

| 操作 | 方式 |
|---|---|
| 收起/展开侧栏 | `Ctrl+B` 或标题栏按钮 |
| 新建会话 | `Ctrl+N`、欢迎页卡片、项目行悬停按钮 |
| 调整侧栏宽度 | 拖动侧栏右缘（青色细线提示），双击复位；宽度与收起状态存 `localStorage['qn-layout']` |
| 切换目标 | 侧栏顶部切换器；输入即搜索，Enter 选第一项，Esc 关闭 |
| 本机目标 | 启动后自动连接（无需凭据）；SSH 目标点选后按认证方式弹密码框或直接连接 |

## 8. 代码结构

```
renderer/index.html              进场页静态标记 + 内联样式
renderer/src/App.tsx             外壳装配、全局快捷键、对话框
renderer/src/components/shell/   TitleBar / Sidebar / TargetSwitcher / ProjectTree / StatusBar / WelcomePane / Logo
renderer/src/hooks/              useBootSplash（进场页驱动）、useDismiss（浮层外点/Esc 关闭）
renderer/src/store/ui.ts         侧栏宽度/收起、目录选择器开关
renderer/src/lib/                splash（时序）、layout（尺寸约束）、targetStatus（状态语义）、time（相对时间），均有单测
main/index.ts                    titleBarOverlay、去菜单、ready-to-show、开发快捷键
preload/index.ts                 暴露 platform，供标题栏决定按钮占位侧
```
