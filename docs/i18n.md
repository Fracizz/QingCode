# 中英文国际化约定

只支持中文与英文。默认跟随系统语言（首选语言是中文则中文，否则英文），可在设置里手动指定，切换后重载界面。

## 写法

- 界面端（桌面 renderer、手机 Web、`codex-client`）：中文原文直接作键，`t('共 {count} 个文件', { count })`。占位符只用 `{name}`，不要把中文拆开拼接，整句进 `t()`。JSX 文本和属性同样要包。
- `t` 从 `@qn/codex-client` 导入；`codex-client` 内部从 `../../protocol/src/i18n` 导入。与局部变量 `t` 重名时改局部变量名。
- daemon、backend、原生层照常发中文，在 `node.en.ts` / `android.en.ts` 登记译文；展示端用 `translateMessage(message)` 翻译。带变量的提示用模板键，如 `'无法读取 {path}'`。
- 词典文件名为 `*.en.ts`，默认导出 `Record<中文, 英文>`。同一原文在所有词典里译法必须一致。

| 词典 | 归属 |
| --- | --- |
| `apps/desktop/src/renderer/src/i18n/components.en.ts` | `components/`、`App.tsx` |
| `apps/desktop/src/renderer/src/i18n/features.en.ts` | `features/` |
| `apps/desktop/src/renderer/src/i18n/core.en.ts` | `store/`、`lib/`、`hooks/` |
| `apps/mobile/web/src/i18n/mobile.en.ts` | 手机 Web |
| `packages/codex-client/src/i18n/shared.en.ts` | `codex-client` |
| `packages/codex-client/src/i18n/node.en.ts` | server、桌面 backend / main / preload / shared |
| `packages/codex-client/src/i18n/android.en.ts` | Android 原生层传给 Web 的提示 |

## 注意

- 切换语言靠重载，模块顶层常量里可以调用 `t()`；入口文件必须先导入 `./i18n`。
- 参与逻辑判断的中文（匹配错误文本、持久化的值、跨进程协议字段）不能直接换成 `t()`；发给模型的提示词保持原样。这类内容在本行或上一行注释 `i18n-ignore: 原因`。
- 英文界面里不应出现中文标点：`、`、`：`、`（）`、`；` 等拼接符也要随语言变化。
- 日期、数字格式按 `getLocale()` 选 `zh-CN` 或 `en-US`，英文注意单复数与词序。
- 英文通常更长，窄控件用简短译法。

## 检查

`pnpm exec vitest run packages/codex-client/src/i18n` 检查漏包、缺译、占位符与译法冲突。只查部分文件时设 `I18N_SCOPE=路径片段1,路径片段2`。
