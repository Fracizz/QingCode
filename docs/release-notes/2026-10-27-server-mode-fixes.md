# Server 模式修复

本次修复覆盖连接管理、信任状态、共享服务与协议边界，共 11 项评估问题。

- 撤销工作区信任会持久保存为受限状态，项目切换不会重新授予权限；撤销时先关闭权限，再清理该项目终端和监听。
- 测试连接使用独立认证，结束后关闭，不修改正在使用的 SSH 会话。后端也拒绝向活会话写入不同的目标或凭据。
- 成功验证绑定当时的连接参数，修改目标或认证参数需重新测试；同指纹主机更换用户名后可正常保存。在线连接保存目标/认证变更前确认断开重连。
- 切换单个连接的 SSH 兼容模式只停止该连接的项目绑定，保留其他项目使用的共享 daemon。显式重启仍会提示共享影响。
- daemon 退出前等待终端终止，必要时强杀，包括刚被单独关闭但尚在回收的终端，避免留下后台任务。
- 目录扫描协商 `fs.scanPaged`，按最多 256 项分页收齐大目录；旧请求超帧返回明确错误，不断开整条连接。
- serve 回退搜索按最终 JSON 大小约束高亮区间和文本，超限明确返回截断结果与结束帧；daemon 分块搜索保持原能力。
- 请求取消在异步派发前登记，紧随请求到达的 CANCEL 不再丢失。
- 文件监听用有效协议帧更新空闲截止，正常心跳不再触发周期性重订阅；退出旧监听时主动关闭通道。
- Server Release 正确生成 Cargo 目标链接器环境变量，使 musl 构建使用配置的 LLD。

回归测试包括真实回环 SSH/SFTP 认证隔离、6000 个长文件名分页、连续请求/取消、密集匹配及转义长行、跨进程关服回收，以及现有前端与 Rust 测试。浏览器内存场景和隔离 Linux SSH 验收产物位于本机 `.dev/server-fix-2026-10-27/`，不随源码提交。

本轮验证：前端 1358 个测试与构建通过；Rust 533 个测试通过，9 个外部条件用例保留忽略，另排除当前环境不可达的 X11 剪贴板用例，fmt/Clippy 通过。隔离 Linux SSH 连续 60 秒验收 25/25 通过；ego 对连接测试隔离与保存重连、目标变化使验证失效、撤信后同步保持受限三组 DOM 交互断言通过。截图接口超时，未完成视觉验收。

本次没有新增 macOS/armv7 服务资产、统一控制通道或跨版本 daemon 共存能力；这些仍属于既有设计中的未完成项。Linux 验收不能替代 Windows OpenSSH/ConPTY 与 macOS 实机验收。
