### English

Patch release with file watching, terminal session persistence, and more reliable definition navigation in packaged Windows builds. WebView2 required on Windows.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.11-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.11-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.11-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.11-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.11-macos-arm64.dmg` / `.zip` |

#### Highlights

- **Workspace**: file watching and persisted terminal sessions
- **Performance**: diagnostics available from Settings
- **Navigation**: Ctrl+click remains reliable when packaged WebView2 drops modifier-key events

#### 下载

| 平台 | 文件 |
|------|------|
| Windows x64 便携 | `QingCode_0.1.11-windows-x64.exe` |

- **工作区**：文件监听与终端会话持久化
