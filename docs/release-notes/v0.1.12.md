## QingCode v0.1.12

**Language / 语言:** [English](#english) · [中文](#中文)

---

<a id="english"></a>

### English

This release adds local-image Markdown previews, independent file windows, single-instance file opening, and Explorer workflow improvements. Windows requires WebView2.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.12-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.12-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.12-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.12-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.12-macos-arm64.dmg` / `.zip` |

#### Highlights

- **Markdown**: preview local relative images
- **Windows**: open files in an independent window, forward requests to the existing instance, and use Ctrl+O to open a system file dialog
- **Workspace**: improved favorites, search, terminal coordination, startup stability, and default installation of all language components

Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.en.md).

### 中文

本版本新增 Markdown 本地图片预览、独立文件窗口和单实例打开转发，并优化资源管理器工作流。Windows 需安装 WebView2。

#### 下载

| 平台 | 文件 |
|------|------|
| Windows x64 便携 | `QingCode_0.1.12-windows-x64.exe` |
| Windows x64 安装包 | `QingCode_0.1.12-windows-x64-setup.exe` |
| Windows ARM64 便携 | `QingCode_0.1.12-windows-arm64.exe` |
| Windows ARM64 安装包 | `QingCode_0.1.12-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.12-macos-arm64.dmg` / `.zip` |

#### 主要变更

- **Markdown**：支持本地相对图片预览
- **Windows**：支持独立文件窗口、单实例打开转发，以及 Ctrl+O 系统文件对话框
- **工作区**：优化收藏夹、搜索、终端配套和启动稳定性；安装包默认安装全部语言组件
