## QingCode v0.1.13-beta.1

**Language / 语言:** [English](#english) · [中文](#中文)

This is a **beta**. In-app “latest” still points at v0.1.12.

<a id="english"></a>

### English

First beta after v0.1.12: SSH remote workspaces, search scoping, a Windows crash fix, and removal of semantic navigation. Windows requires WebView2.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.13-beta.1-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.13-beta.1-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.13-beta.1-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.13-beta.1-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.13-beta.1-macos-arm64.dmg` / `.zip` |

#### Highlights

- **SSH**: remote projects, fingerprint confirmation, remote files/terminals, and run configs
- **Search**: pick folders and types; Ctrl+Shift+F follows the Explorer folder
- **Stability**: Windows heap-corruption crash from a cross-thread event-loop `Rc` race
- **Removed**: Go to Definition, Find Usages, workspace symbols, and language components

Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/test/CHANGELOG.en.md).

### 中文

v0.1.12 之后的第一个 beta：SSH 远程工作区、搜索范围、Windows 闪退修复，并移除语义导航。Windows 需安装 WebView2。

#### 下载

| 平台 | 文件 |
|------|------|
| Windows x64 便携 | `QingCode_0.1.13-beta.1-windows-x64.exe` |
| Windows x64 安装包 | `QingCode_0.1.13-beta.1-windows-x64-setup.exe` |
| Windows ARM64 便携 | `QingCode_0.1.13-beta.1-windows-arm64.exe` |
| Windows ARM64 安装包 | `QingCode_0.1.13-beta.1-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.13-beta.1-macos-arm64.dmg` / `.zip` |

#### 主要变更

- **SSH**：远程项目、主机指纹确认、远程文件/终端与运行配置
- **搜索**：自选目录与类型；Ctrl+Shift+F 跟随资源管理器目录
- **稳定性**：修复 Windows 事件循环跨线程 `Rc` 竞态导致的堆损坏闪退
- **移除**：转到定义、查找用法、工作区符号及语言组件
