The second v0.1.13 beta adds settings transfer and default reset, improves project management, and refines the interface, SSH recovery, Markdown, and terminal workflows.

#### Highlights since beta.1

- **Settings transfer**: import/export user or workspace settings, including local project lists in user exports. Reset either scope to defaults through Settings or the CLI; AI CLI Skill guidance includes the same commands. Credentials, trust grants, and sessions are excluded from exports. JSON5 comments and settings inheritance are preserved.
- **Project management**: search by project name or path and re-import removed projects.
- **SSH recovery**: session and authentication errors retain the project and a retry path; connected hosts with missing directories still report the directory error. File-tree errors remain visible and retryable.
- **Editing and Git**: Markdown copy/link actions, workspace-file navigation from Git history diffs, and improved history hash display.
- **Interface**: tighter tab and project spacing, consistent typography, corners and controls, clearer themes, an olive-green Forest theme, reduced-motion support, and updated icons.
- **Reliability**: improved search cancellation, SSH transfer progress/cancellation, terminal output queues, panel resizing, and Windows file associations. Fixed the Rust Clippy check that blocked the previous beta release.

Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/v0.1.13-beta.2/CHANGELOG.en.md). Settings transfer: [documentation](https://github.com/Fracizz/QingCode/blob/v0.1.13-beta.2/docs/settings-transfer.md).

#### 相比 beta.1 的主要变更

- **配置迁移**：支持用户与工作区配置导入、导出，用户导出包含本地项目列表；设置界面和 CLI 均可恢复对应范围的默认设置，AI CLI Skill 同步提供命令说明。导出不包含凭据、信任授权和会话，保留 JSON5 注释与设置继承关系。
- **项目管理**：按项目名称或路径搜索，修复移除项目后无法重新导入的问题。
- **SSH 重连**：会话和认证错误保留项目与重试入口；已连接但目录不存在时仍显示实际目录错误。文件树错误可见并支持重试。
- **编辑与 Git**：完善 Markdown 复制与链接操作，支持从 Git 历史差异跳转到工作区文件，改善历史哈希显示。
- **界面**：收紧标签和项目间距，统一字号、圆角和按钮，提升主题清晰度，森林主题改为橄榄绿，完善减少动态效果偏好并更新图标。
- **可靠性**：改进搜索取消、SSH 传输进度与取消、终端输出队列、面板拖动和 Windows 文件关联；修复阻塞上次 beta 发布的 Rust Clippy 检查问题。
