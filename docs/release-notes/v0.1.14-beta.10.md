## QingCode v0.1.14-beta.10

### 中文

本测试版修复空闲会话持续提交文件监视请求的问题，并包含 beta.9 之后的 Server 直连和终端恢复改进。

- **窗口响应**：会话保存跳过未变化的编辑内容，文件监视只在路径集合变化时同步；慢请求期间合并后续配置，避免重复 IPC 请求持续积累。
- **远程连接**：支持 Server 端口直连，改进 Windows 直连准备、连接复用、版本校验和服务包恢复提示。
- **终端**：修复复制、右键交互及直连粘贴上传问题，完善会话快照恢复、控制资源隔离和恢复诊断。

验证：1505 项前端测试、前端完整检查及 Windows x64 原生构建通过；原生设置、搜索和资源管理器交互通过，修复后的约 5 分钟观察未出现重复文件监视同步或请求积压。尚未复验十余小时的持续运行场景。

提供 Windows x64、Windows ARM64 和 macOS Apple Silicon 安装包及便携版；配套远端 Server 版本为 `0.1.14-beta.10`。Windows 需要 WebView2；macOS 未签名构建首次可能需要右键选择“打开”。

### English

This prerelease fixes repeated file watch requests from idle sessions and includes the Server direct-connection and terminal recovery improvements made since beta.9.

- **Window responsiveness**: session persistence skips unchanged editor contents, and file watches synchronize only when their paths change. Slow requests coalesce subsequent configurations to prevent repeated IPC requests from accumulating.
- **Remote connections**: direct connections to Server ports, with improved Windows preparation, connection reuse, version checks and server package recovery messages.
- **Terminals**: fixes for copy, context menu and paste-upload behavior over direct connections, plus improved snapshot recovery, control resource isolation and recovery diagnostics.

Validation: all 1,505 frontend tests, frontend checks and the Windows x64 native build passed. Native settings, search and explorer interactions passed; approximately five minutes of observation showed no repeated file watch synchronization or queued requests. The original scenario involving more than ten hours of continuous operation has not been repeated.

Includes Windows x64 and ARM64 installers and portable builds, and macOS Apple Silicon DMG and ZIP. The matching remote Server version is `0.1.14-beta.10`. Windows requires WebView2; unsigned macOS builds may require right-click → Open on first launch.
