## QingCode v0.1.14-beta.12

### 中文

- Windows 安装与覆盖升级自动关闭目标安装目录中的运行实例，保留其他安装目录的实例和用户数据。
- 安装结束默认勾选运行 QingCode，支持取消启动；首次安装和同版本重装需点击「开始安装」，旧版本升级可自动覆盖。
- 修复 Windows CRLF 换行导致的安装器测试失败。

验证：1505 项前端测试、8 项打包脚本测试、TypeScript、Rust fmt、Clippy 和 Rust 测试通过；Windows x64 安装包及 Server 离线包本地构建成功。ESLint 无错误，现有 41 项警告。

### English

- Windows installation and upgrades close the app in the target installation directory while preserving other installations and user data.
- Launch QingCode is selected by default on the finish page and remains optional. First installs and same-version reinstalls require Start Install; upgrades from older versions can run automatically in place.
- Fix installer tests on Windows files using CRLF line endings.

Validation: 1,505 frontend tests, 8 packaging tests, TypeScript, Rust fmt, Clippy and Rust tests passed. Windows x64 installer and offline Server package built locally. ESLint reports no errors and 41 existing warnings.
