## QingCode v0.1.14-beta.24

### 中文

- Android 配套远程终端新增扫码配对、长期有效的配对信息和多设备连接管理。
- 优化移动连接保存、密码设置与端口切换，以及并行更新进度展示。
- 终端连接状态使用浮层提示，改进 daemon 输出补发。
- 修复终端长时间运行后字形错乱的问题。
- 客户端与 Server 版本统一更新为 0.1.14-beta.24，提供独立 Server 离线包。

Windows 需要 WebView2。macOS 应用未签名，首次启动请右键选择“打开”。Android APK 仅在发布签名密钥已配置时提供。

### English

- Add QR pairing, persistent pairing information and multi-device connection management to the Android companion terminal.
- Improve mobile connection saving, password configuration, port changes and parallel update progress.
- Show terminal connection status in an overlay and improve daemon output replay.
- Fix corrupted terminal glyphs after long-running sessions.
- Align the desktop and Server versions at 0.1.14-beta.24 and provide a separate Server offline package.

Windows requires WebView2. The macOS app is unsigned; right-click and choose Open on first launch. The Android APK is included only when release signing credentials are configured.
