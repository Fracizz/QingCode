## QingCode v0.1.14-beta.7

**Language / 语言:** [English](#english) · [中文](#中文)

This prerelease does not replace the stable release used by in-app update checks.

<a id="english"></a>
### English

This beta expands SSH workspaces and improves remote terminal recovery, project management, and run configurations.

- **SSH and Server mode:** persistent terminals, reconnect and lifecycle improvements, connection-level mode selection, isolated connection tests, trust handling, and safer server deployment. Import multiple connections from the local SSH configuration.
- **Remote files and Git:** upload local files from the explorer or clipboard, view images, and use Git in Windows SSH projects. Project-scoped Git status and file watching have been improved.
- **Projects and tasks:** clearer local, WSL and SSH project identification, an idle editor for open projects, and cross-platform run configurations with batch operations.
- **Reliability:** improved Windows SSH terminal handling, cancellation, paged directory scanning, search limits, cleanup of remote terminal processes, and a three-hour retention period for disconnected remote terminals.

Windows x64 and ARM64 installers and portable builds, macOS Apple Silicon DMG and ZIP, and an offline server pack are available below. Windows requires WebView2; unsigned macOS builds may require right-click → Open on first launch. Server binaries can also be downloaded automatically from the corresponding server release.

<a id="中文"></a>
### 中文

本测试版扩展 SSH 工作区，改进远程终端恢复、项目管理和运行配置。它不会替代应用内更新检查使用的稳定版。

- **SSH 与 Server 模式**：支持终端持久化和断线恢复、连接级模式选择、隔离的连接测试、信任状态处理及更安全的 Server 部署；可从本机 SSH 配置批量导入连接。
- **远程文件与 Git**：支持从资源管理器或剪贴板上传本机文件、查看图片，以及在 Windows SSH 项目中使用 Git；改进项目范围内的 Git 状态与文件监听。
- **项目与任务**：更清晰地区分本地、WSL 和 SSH 项目；为已打开项目提供空闲编辑区，支持跨平台运行配置和批量操作。
- **稳定性**：改进 Windows SSH 终端、请求取消、目录分页、搜索限制远程终端进程清理，并将断线终端默认保留时长调整为三小时。

下方提供 Windows x64、ARM64 安装包和便携版，macOS Apple Silicon DMG、ZIP，以及离线 Server 包。Windows 需要 WebView2；macOS 未签名构建首次可能需要右键 → 打开。Server 二进制也可从对应的独立 Server Release 自动下载。
