## QingCode v0.1.14-beta.9

### 中文

本测试版基于 `beta.8` 发布，功能内容相同，更新了应用和远端 Server 的版本号并重新构建各平台安装包。已安装 `beta.8` 的用户无需因功能变化升级。

提供 Windows x64、Windows ARM64 和 macOS Apple Silicon 安装包及便携版，另有离线 Server 包。Windows 需要 WebView2；macOS 未签名构建首次可能需要右键选择“打开”。

### English

This prerelease rebuilds `beta.8` with updated application and remote server version numbers. It contains the same product functionality; existing `beta.8` users do not need to upgrade for new features.

The release includes Windows x64 and ARM64 installers and portable builds, macOS Apple Silicon DMG and ZIP, and an offline server package. Windows requires WebView2; unsigned macOS builds may require right-click → Open on first launch.
