## QingCode v0.1.15-beta.1

### 中文

- Android 支持多选图片并依次上传，部分失败时保留已经上传的附件。
- Android 会话侧栏支持重命名、长按菜单、本机置顶、最近项目和批量结束会话。
- 修复 Android 终端历史和会话操作，改善网络请求可靠性，并修复折叠快捷键后终端底行被遮挡的问题。

配套远端 Server 版本为 `0.1.15-beta.1`。

### English

- Android supports selecting and uploading multiple images in order, retaining successful attachments after a partial failure.
- The Android session drawer supports renaming, long-press actions, local pinning, recent projects, and ending all sessions in a project.
- Fixed Android terminal history and session actions, improved request reliability, and kept the last terminal row visible when shortcuts are collapsed.

The matching remote Server version is `0.1.15-beta.1`.
