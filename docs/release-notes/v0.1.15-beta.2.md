## QingCode v0.1.15-beta.2

### 中文

- Android 返回终端优先界面，首页恢复终端，导航调整为「终端 / 项目 / 连接」。
- 保留多图附件、会话重命名、长按菜单、本机置顶、最近项目和批量结束会话等改进。
- 修复终端底行遮挡、切换会话时附件串入其他草稿，以及部分请求可靠性问题。

配套远端 Server 版本为 `0.1.15-beta.2`。

### English

- Android returns to a terminal-first interface with Terminal as the home tab and "Terminal / Projects / Connections" navigation.
- Keeps multi-image attachments, session renaming, long-press actions, local pinning, recent projects, and ending all sessions in a project.
- Fixes the obscured final terminal row, attachments leaking between drafts during session changes, and several request reliability issues.

The matching remote Server version is `0.1.15-beta.2`.
