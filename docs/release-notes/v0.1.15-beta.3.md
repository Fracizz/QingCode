## QingCode v0.1.15-beta.3

### 中文

- 终端支持 `Ctrl+Enter`（macOS 同时支持 `Cmd+Enter`）发送换行，右键菜单也可执行同一操作。
- 增大终端多段输入区域，方便查看和编辑较长需求。
- 包含 beta.2 的 Android 终端优先界面、多图附件和会话操作改进。

配套远端 Server 版本为 `0.1.15-beta.3`。

### English

- The terminal supports `Ctrl+Enter` (`Cmd+Enter` on macOS) to send a newline, also available from the context menu.
- Enlarged the terminal multi-line input area for easier review and editing of longer requests.
- Includes the terminal-first Android interface, multi-image attachments, and session improvements from beta.2.

The matching remote Server version is `0.1.15-beta.3`.
