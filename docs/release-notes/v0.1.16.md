### English

The first stable release after v0.1.12. It rolls up the 0.1.13–0.1.16 beta line: SSH remote workspaces with a remote Server and an Android companion, a reworked terminal, and a refreshed interface. This release becomes the version used by in-app update checks.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.16-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.16-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.16-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.16-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.16-macos-arm64.dmg` / `.zip` |
| Android 8.0+ (companion remote terminal) | `QingCode_0.1.16-android.apk` |
| Offline Server package | `QingCode_0.1.16-servers.zip` |

Windows requires WebView2; unsigned macOS builds may need right-click → Open on first launch.

#### Highlights

- **SSH remote workspaces**: remote projects with host-fingerprint confirmation and root-boundary/trust checks, remote file tree, editing and uploads, image preview, remote PTY terminals that survive disconnects, remote Git, run configurations, and SFTP transfer. Connections can be imported from the local SSH config.
- **Remote Server**: connections run through a versioned QingCode Server with reuse, latency display, automatic redeploy on version mismatch, and bundled online/offline server packages.
- **Android companion**: QR pairing with long-lived pairing details and multi-device management, terminal-first layout with Chinese/English UI, multi-image attachments, session drawer with rename, pinning, long-press actions and keyword search, mouse mode with a draggable virtual pointer, paged full-screen programs with a rubber-band scrollbar, colored history, and in-app updates.
- **Terminal**: `Ctrl+Enter` newline, a larger composer, long pastes saved to a file with the path inserted, independent font settings and zoom, content export, snapshot recovery, a fix for corrupted glyphs after long sessions, CLI access to list and drive terminals, and activity badges/background notifications.
- **Search and explorer**: choose folders and file types to search, `Ctrl+Shift+F` follows the Explorer folder, correct refresh for added/deleted/renamed entries, and paged directory scanning.
- **Settings and projects**: import/export user or workspace settings with JSON5 comments preserved, reset to defaults from the UI or CLI, project search and re-import, run-configuration discovery, and clearer local/WSL/SSH project identification.
- **Windows integration**: single-instance file opening, independent file windows, `Ctrl+O`, configurable text read modes for DLP or encrypted files, open-with registration, and an installer that closes the running instance in the target directory, bundles the Server package and can launch the app when finished.
- **Reliability and interface**: fixed a Windows heap-corruption crash from a cross-thread event-loop race, stopped idle sessions from repeating file-watch requests, tightened spacing/typography/controls, an olive-green Forest theme, reduced-motion support, and a simplified status bar.
- **Removed**: Go to Definition, Find Usages, workspace symbols and the language components; the terminal tab run-state indicator.

The matching remote Server version is `0.1.16`. Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/test/CHANGELOG.en.md).

v0.1.12 之后的第一个稳定版，汇总 0.1.13–0.1.16 测试线：SSH 远程工作区与远端 Server、Android 配套终端、重做的终端体验和更新后的界面。本版本将成为应用内更新检查使用的稳定版。

#### 主要变更

- **SSH 远程工作区**：远程项目支持主机指纹确认与项目根边界/信任校验，提供远程文件树、编辑与上传、图片预览、断线可恢复的远程终端、远程 Git、运行配置和 SFTP 传输；可从本机 SSH 配置导入连接。
- **远端 Server**：连接经带版本校验的 QingCode Server 运行，支持连接复用、延迟显示、版本不匹配时自动重新部署，并提供内置的在线/离线服务包。
- **Android 配套终端**：扫码配对与长期有效的配对信息、多设备管理；终端优先布局与中英文界面；多图附件；会话侧栏支持重命名、置顶、长按菜单与关键词搜索；鼠标模式可拖动虚拟指针；全屏程序按格滚动并带阻尼滚动条；历史保留颜色；应用内更新。
- **终端**：`Ctrl+Enter` 换行、更大的多段输入区、长文本粘贴存为文件并插入路径、独立字体设置与缩放、内容导出、快照恢复、修复长时间运行后的字形错乱、CLI 可列出并驱动终端、活动角标与后台提醒。
- **搜索与资源管理器**：可指定搜索目录与文件类型，`Ctrl+Shift+F` 跟随资源管理器目录；刷新能正确同步新增、删除与重命名；目录分页扫描。
- **设置与项目**：用户/工作区配置导入导出并保留 JSON5 注释，界面或 CLI 均可恢复默认；项目搜索与重新导入；运行配置自动发现；更清晰地区分本地、WSL 与 SSH 项目。
- **Windows 集成**：单实例打开文件、独立文件窗口、`Ctrl+O`、适配 DLP 或加密文件的文本读取模式、资源管理器“打开方式”注册；安装包会关闭目标目录中运行中的应用、内置 Server 服务包并可选择安装后启动。
- **稳定性与界面**：修复 Windows 事件循环跨线程竞态导致的堆损坏闪退，修复空闲会话重复提交文件监视请求；收紧间距、字号与控件，森林主题改为橄榄绿，支持减少动态效果，精简状态栏。
- **移除**：转到定义、查找用法、工作区符号及相关语言组件；终端标签的运行状态指示。

配套远端 Server 版本为 `0.1.16`。完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/test/CHANGELOG.md)。
