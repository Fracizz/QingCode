## QingCode v0.1.17-beta.3

### 中文

v0.1.16 之后的测试版，集中改进终端右键菜单、输入法输入体验和 Android 配套终端。

#### 主要变更

- 终端右键新增「添加到对话」：选中 Claude Code、opencode 等 AI CLI 的输出可直接引用回输入框继续追问；仅在开启 bracketed paste 时可用，避免普通 Shell 误执行。
- 精简终端右键菜单：按选区、可写状态和 AI CLI 状态隐藏不可用项；复制当前屏幕、导出内容、清理远程粘贴文件移入命令面板。
- 修复输入法组字时终端画面被顶起的问题，锁定终端宿主的滚动位置。
- Android：通用设置集中到设置页，补齐弹层退出与按压动效，系统下拉统一为项目风格的选择面板，横屏保留状态栏。
- Android：修复会话提交列表行重叠，加宽虚拟鼠标并换成更利落的箭头；修复滚动条滑块越界和关闭单个会话时的闪动。
- WSL 项目不再重复显示 WSL 标签，列表路径改为「发行版:路径」（例如 `Ubuntu:/home/...`）。

配套远端 Server 版本为 `0.1.17-beta.3`。

### English

A beta after v0.1.16, focused on the terminal context menu, IME input, and the Android companion.

#### Highlights

- The terminal context menu gains "Add to conversation": select output from Claude Code, opencode, or another AI CLI and quote it back into the composer; it is enabled only when bracketed paste is on so plain shells never execute it accidentally.
- A slimmer terminal context menu hides unavailable items based on selection, writability, and AI CLI state; copy current screen, export, and clean remote paste files moved into the command palette.
- Fixed the terminal being pushed up while the IME composes text by locking the terminal host's scroll position.
- Android: general settings now live on the settings page, with layered panel exit and press animations, a project-style picker replacing native dropdowns, and a status bar kept in landscape.
- Android: fixed overlapping rows in the session submit list, widened the virtual pointer with a cleaner arrow, and fixed the scrollbar thumb leaving its track and the flicker when closing a single session.
- WSL projects no longer show a duplicate WSL badge, and their paths use `distro:path` (for example `Ubuntu:/home/...`).

The matching remote Server version is `0.1.17-beta.3`.
