### English

The stable release after v0.1.16. It rolls up the 0.1.17 beta line: the terminal workbench, cross-device terminal reattach, multi-device Git sync, SSH direct-connect and tunnel improvements, and a refined Android companion. This release becomes the version used by in-app update checks.

Windows requires WebView2; unsigned macOS builds may need right-click → Open on first launch.

#### Highlights

- **Terminal workbench**: a panel layout with all projects' terminals grouped on the left, the terminal in the center and the editor opening beside it only when needed; search, source filters, creation times, running-first sorting, drag reordering, and batch management.
- **Terminal reattach**: local terminals survive quitting the app through a background host; remote terminals reattach by compatibility level. Phones, tablets, and computers can attach to each other's terminals with exclusive use, while the computer can watch read-only in real time.
- **Multi-device Git sync**: event-driven, parallel per machine with the current project first, shown in one grouped table with loading states and localized non-fast-forward hints.
- **SSH and remote Server**: Server mode reaches the direct-connect gateway through an SSH tunnel sharing one channel with port direct connect; background prewarming runs per connection; credentials can be saved encrypted; health probing and retry make reconnects more reliable.
- **Terminal input**: "Add to conversation" quotes AI CLI output back into the composer; fixed the terminal being pushed up while the IME composes text; `Shift+Enter`, link handling, and shortcut-bar reordering on Android.
- **Android companion**: an "All" session overview, a persistent tablet sidebar, keep-screen-awake, project path copy, circular pull-to-refresh, a wider virtual pointer, and reattach after the PC restarts, upgrades, or changes ports.
- **Interface**: dark and olive themes aligned to neutral layering with a unified terminal background; project hover info cards with path copy; clearer local/WSL/SSH project identification; slimmer Android UI with project-style pickers.

The matching remote Server version is `0.1.17`. Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/test/CHANGELOG.en.md).

v0.1.16 之后的稳定版，汇总 0.1.17 测试线：终端工作台、多端终端接回、Git 多端同步、SSH 直连与隧道改进，以及打磨后的 Android 配套终端。本版本将成为应用内更新检查使用的稳定版。

| Windows ARM64 便携 | `QingCode_0.1.17-windows-arm64.exe` |

Windows 需安装 WebView2；macOS 未签名构建首次可能需要右键 → 打开。

#### 主要变更

- **终端工作台**：左侧按项目分组列出全部终端，终端居中，打开文件时编辑器才在右侧展开；支持搜索、来源筛选、创建时间、运行中优先排序、拖拽排序与批量管理。
- **终端接回**：本地终端由后台宿主托管，退出应用后可接回；远程终端按兼容级别判定接回。手机、平板与电脑可互相接入终端，同一时刻独占使用，电脑可只读实时观看。
- **Git 多端同步**：事件驱动、按机器并行并优先当前项目，单表分组显示并在读取完成前显示加载；无法快进的提示改为本地化文案。
- **SSH 与远端 Server**：Server 模式经 SSH 隧道接入直连网关，与端口直连共用一条通道；后台预热按连接并发；凭据可加密保存；增加探活与重试，重连更可靠。
- **终端输入**：右键「添加到对话」可引用 AI CLI 输出继续追问；修复输入法组字时终端画面被顶起；支持 `Shift+Enter`、终端链接与手机快捷键栏拖动排序。
- **Android 配套终端**：会话「全部」纵览、平板常驻侧栏、屏幕常亮、项目路径复制、圆形下拉刷新、加宽虚拟鼠标；电脑重启升级或更换端口后仍可接回。
- **界面**：深色与橄榄绿主题对齐中性分层并统一终端底色；项目悬停提示统一为信息卡片并支持复制路径；更清晰地区分本地、WSL 与 SSH 项目；手机端界面精简并使用项目风格选择面板。

配套远端 Server 版本为 `0.1.17`。完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/test/CHANGELOG.md)。
