## QingCode v0.1.18-beta.6

### 中文

v0.1.17 之后的测试版，集中改进主题与终端配色、Git 多端同步和远程项目打开体验。

#### 主要变更

- 新增「石墨灰」逐级分层中性灰主题：标题栏、图标栏、侧栏、内容区依次变暗并以细线分割，与平铺的深色主题区分。
- 深色、石墨灰与浅色终端改为柔和配色：去掉纯白/纯黑，ANSI 色降饱和，选区改中性灰，正文对比度仍保持可读。
- 橄榄绿改为低饱和护眼绿，石墨灰标题同样改用低饱和青绿，降低刺眼感。
- Android 新增深色与石墨灰两套主题，可在设置中切换，并与桌面共用柔和终端配色。
- 远程项目按 SSH 连接并发打开：不同连接的打开/安装/更新互不取消、各自显示进度卡，同一连接共享任务。
- Git 同步通知显示为「项目名 + 来源徽标」，多端同步更容易区分来源。
- 降低 Git 多端同步延迟：按仓库预筛接收项目，改用轻量跟踪查询，推送后无关仓库不再排队。
- 加快 Windows 服务包 SFTP 上传：改用 256 KiB 分块写入，避免小分块在 Windows OpenSSH 上过慢。
- 修复空闲终端改尺寸后的整段重绘被误判为运行中，导致无人查看的终端被标「待查看」并刷新时间。

配套远端 Server 版本为 `0.1.18-beta.6`。

### English

A beta after v0.1.17, focused on themes and terminal colors, multi-device Git sync, and remote project opening.

#### Highlights

- New "Graphite" layered neutral-gray theme: title bar, icon rail, sidebar, and content area darken step by step with thin separators, distinct from the flat dark theme.
- Softened terminal palettes for dark, graphite, and light themes: no pure white or black, desaturated ANSI colors, neutral-gray selection, with readable body contrast preserved.
- Olive theme became a low-saturation eye-friendly green; the graphite title uses the same softer green to reduce glare.
- Android gains dark and graphite themes that switch in settings and share the desktop's softened terminal palette.
- Remote projects open concurrently per SSH connection: open/install/update tasks on different connections no longer cancel each other and each shows its own progress card, while tasks on the same connection are shared.
- Git sync notifications now show "project name + source badge" so multi-device sync is easier to tell apart.
- Lower Git multi-device sync latency: receiver projects are pre-filtered per repository and use lightweight tracking queries, so unrelated repositories no longer queue after a push.
- Faster Windows server package upload over SFTP: 256 KiB chunks avoid slow small writes on Windows OpenSSH.
- Fixed idle terminals being marked "needs attention" and refreshing their timestamp when a resize-triggered full redraw was treated as running output.

The matching remote Server version is `0.1.18-beta.6`.
