## QingCode v0.1.19-beta.9

**Language / 语言:** [English](#english) · [中文](#中文)

---

<a id="english"></a>

### English

A beta after v0.1.19 that finishes one-click Server direct connections, switches Windows terminals to the bundled ConPTY, and improves mobile interaction.

#### Highlights

- Server port direct connection gains "One-click enable": after a single SSH authorization it installs or reads the service, allows the firewall port, checks the certificate, verifies credentials, and enables the connection. Step-by-step setup is still available, and it no longer requires opening a project first.
- One-click Server direct connection is much faster on Windows remotes: the firewall rule is applied while the service installs, the digest check and self-check of an installed binary run in one remote call, and pairing info is read over SFTP, saving about four PowerShell cold starts.
- Windows terminals now use the bundled ConPTY (Microsoft `conpty.dll` + `OpenConsole.exe`, for local terminals and remote Windows in Server mode): programs that request mouse reporting before switching input modes, such as pi in fullscreen mode, scroll their conversation with the wheel instead of cycling input history. Set `QINGCODE_INBOX_CONPTY=1` to fall back to the system ConPTY.
- The local terminal host is separated per build: after an upgrade, new terminals start in the new host, while terminals opened before the upgrade stay in the old host and can still be reattached and closed.
- The remote connection editor pre-fills the locally saved SSH password (masked); click the eye icon to reveal it, and new connections default to password authentication.
- Mobile: the fullscreen-program slider gains a "Bottom" button that scrolls down automatically until the screen stops changing (at most 10 seconds).
- Mobile: session list timestamps now show "active at" instead of "created at".

The matching remote Server version is `0.1.19-beta.9`.

<a id="中文"></a>

### 中文

v0.1.19 之后的测试版，集中完善 Server 直连的一键启用与 Windows 终端体验，并改进手机端操作。

#### 主要变更

- Server 端口直连新增「一键启用直连」：通过 SSH 授权一次后，自动完成安装或读取服务、放行防火墙端口、核对证书、验证凭据并启用，无需再分步操作；分步配置仍保留，且不再需要先打开项目。
- 一键启用 Server 直连在 Windows 远端明显提速：放行端口与安装服务并行执行，已安装程序的摘要校验与自检合并为一次远端调用，网关配对信息改经 SFTP 读取，少冷启动约 4 次 PowerShell。
- Windows 终端改用随程序携带的新版 ConPTY（Microsoft `conpty.dll` + `OpenConsole.exe`，本机终端与 Server 模式远端 Windows 均生效）：pi 全屏模式等先请求鼠标、后切输入模式的程序，滚轮不再被转成方向键翻输入历史，可正常滚动会话；设置环境变量 `QINGCODE_INBOX_CONPTY=1` 可退回系统 ConPTY。
- 本机终端宿主按构建区分：升级后新开的终端进入新版宿主，升级前打开的终端仍留在旧宿主并可正常接回、关闭，全部结束后旧宿主自动退出。
- 远程连接编辑页默认回填本机已保存的 SSH 密码（以圆点遮挡），点眼睛即可查看；新建连接默认使用密码认证。
- 手机：全屏程序滑块新增「到底」按钮，自动下滑直到画面不再变化（最长 10 秒）。
- 手机：会话列表时间由「创建于」改为「活动于」。

配套远端 Server 版本为 `0.1.19-beta.9`。
