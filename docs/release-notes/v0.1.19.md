### English

The stable release after v0.1.17. It rolls up the 0.1.18 beta line: terminal and coding-CLI prewarming, three-way terminal sharing across devices, Windows SSH run tasks, a redesigned terminal list, and a smoother desktop and Android experience. This release becomes the version used by in-app update checks.

Windows requires WebView2; unsigned macOS builds may need right-click → Open on first launch. For updating a remote Server without internet access, see [Offline Server update](https://github.com/Fracizz/QingCode/blob/master/docs/server-offline-update.md).

#### Highlights

- **Faster terminals**: shells are prewarmed per host (local Windows, remote Windows and Linux/macOS in Server mode) and reused across project switches; Claude Code, Codex, and OpenCode can be prewarmed to open trusted projects faster. Prewarming pauses with a visible reason when the remote daemon is outdated.
- **Windows SSH run tasks**: run configurations now work in Windows SSH projects. `command` runs through `cmd` like local Windows, and `ps1`, `bat`, `sh`, and `script` tasks are dispatched by type, in both direct SSH and Server mode.
- **Multi-device terminals**: computer, phone, and tablet can view the same terminal at once and take over input explicitly; a terminal can follow the exclusive device's size; "disconnect other devices" and shared-state badges.
- **Terminal list redesign**: fixed status column, color-coded source labels, grouping and drag-reordering by host, a "More" menu for low-frequency actions, creation times, and smoother scrolling and switching animations.
- **Terminal input**: clear pending input works with AI CLI multi-line composers; selected text can be brought into a long-text editor; `Ctrl`+click opens paths with `%TEMP%`-style variables and Git Bash drive syntax, including files outside the project.
- **Remote Server**: per-connection concurrent prewarming and updates, recovery of interrupted upgrades, confirmation of updates with active terminals, and faster Windows package uploads.
- **Android companion**: project file browsing with background downloads, continuous terminal output push, customizable shortcut bar, full-width session drawer with two-line headers, dark and graphite themes, and untrusted desktop projects shown greyed out.
- **Interface**: new Graphite theme and softened terminal palettes, smooth sidebar and page transitions with a motion switch, image viewer zoom/pan/rotate, Markdown preview context menu, and remote file properties.

The matching remote Server version is `0.1.19`. Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.en.md).

v0.1.17 之后的稳定版，汇总 0.1.18 测试线：终端与编码 CLI 预热、三端同时查看终端、Windows SSH 运行任务、终端列表改版，以及更顺滑的桌面与 Android 体验。本版本将成为应用内更新检查使用的稳定版。

#### 主要变更

- **终端更快打开**：Shell 按主机预热（本机 Windows、Server 模式下的远端 Windows 与 Linux/macOS），切换项目时复用；Claude Code、Codex、OpenCode 可预热，打开受信任项目更快。远端 daemon 过旧时暂停预热并显示原因。
- **Windows SSH 运行任务**：Windows SSH 项目支持运行配置。`command` 与本地 Windows 一致经 `cmd` 执行，`ps1`、`bat`、`sh`、`script` 按类型分派，直连与 Server 模式均可用。
- **多端终端**：电脑、手机、平板可同时查看同一终端并显式接管输入；终端可跟随独占端尺寸；支持「断开其他端」与共享状态角标。
- **终端列表改版**：行首固定状态位、来源分色标签、按主机分组与拖拽排序、低频操作收进「更多」、显示创建时间，滚动与切换动效更顺滑。
- **终端输入**：清除输入支持 AI CLI 多行输入框；选中文字可带入长文本编辑；`Ctrl`+点击路径支持 `%TEMP%` 等变量与 Git Bash 盘符写法，可打开项目外文件。
- **远端 Server**：按连接并发预热与更新，中断的升级可恢复，有活动终端时可确认后更新，Windows 服务包上传更快。
- **Android 配套终端**：项目文件浏览与后台下载、终端输出持续推送、可自定义快捷键栏、全宽会话抽屉与两行组头、深色与石墨灰主题，电脑上未信任的项目置灰显示。
- **界面**：新增石墨灰主题与柔和终端配色，侧栏与页面切换平滑过渡并提供动效开关，图片查看器支持缩放/平移/旋转，Markdown 预览右键菜单，远程文件属性。

配套远端 Server 版本为 `0.1.19`。完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.md)。
