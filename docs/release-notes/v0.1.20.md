### English

The stable release after v0.1.19. This release makes Server direct connections a one-click setup, ships the newer bundled ConPTY so fullscreen programs such as pi scroll correctly, keeps `Ctrl`+click on file paths working while a terminal is constantly redrawing, and makes attaching to a terminal from the phone noticeably faster.

#### Highlights

- **One-click Server direct connection**: a single SSH authorization now installs or reads the service, allows the firewall port, checks the certificate, verifies credentials and enables the connection; step-by-step setup is still available. On Windows remotes the firewall rule is applied while the service installs, the digest check and self-check run in one remote call, and pairing info is read over SFTP, saving about four PowerShell cold starts.
- **Bundled ConPTY on Windows**: terminals — local and remote Windows in Server mode — now use the shipped `conpty.dll` / `OpenConsole.exe`. Programs that request mouse reporting before switching input modes (for example pi in fullscreen mode) scroll their own conversation with the wheel instead of cycling input history. `QINGCODE_INBOX_CONPTY=1` falls back to the system ConPTY.
- **Per-build terminal host**: after an upgrade new terminals start in the new host so fixes take effect immediately, while terminals opened before the upgrade stay reattachable in the old host, which exits once they all end.
- **Reliable `Ctrl`+click paths**: with Claude Code or another constantly redrawing program, the path under the pointer is re-detected at mouse release and opened, instead of being lost in the gap between redraw writes.
- **Faster phone attach**: when the phone grid differs from the terminal, the attach request carries the phone grid, so the desktop resizes immediately and replies once the redraw settles — two round trips and a ~0.9 s idle wait saved, and a shell that does not redraw now waits at most 0.4 s instead of over 1 s. Requires updating both the desktop app and the Android APK.
- **Mobile and project polish**: a "Bottom" button on the fullscreen-program slider scrolls down until the screen stops changing (at most 10 seconds), session list timestamps show "active at", and the project picker shows SSH connection-name tags and can be filtered by connection name.
- **Remote connection editor**: pre-fills the locally saved SSH password (masked); click the eye icon to reveal it.

The matching remote Server version is `0.1.20`. Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.en.md).

### 中文

v0.1.19 之后的稳定版。本版本把 Server 端口直连做成一键启用，Windows 终端改用随包 ConPTY（pi 等全屏程序滚轮恢复正常），终端持续重绘时 `Ctrl`+点击路径也能可靠打开，手机接入终端明显更快。

| Windows x64 安装包 | `QingCode_0.1.20-windows-x64-setup.exe` |
| Windows ARM64 便携 | `QingCode_0.1.20-windows-arm64.exe` |

#### 主要变更

- **Server 直连一键启用**：通过 SSH 授权一次，即自动完成安装或读取服务、放行防火墙端口、核对证书、验证凭据并启用，无需再分步操作；分步配置仍保留。Windows 远端明显提速：放行端口与安装服务并行执行，已安装程序的摘要校验与自检合并为一次远端调用，网关配对信息改经 SFTP 读取，少冷启动约 4 次 PowerShell。
- **Windows 终端改用随包 ConPTY**：本机终端与 Server 模式远端 Windows 均使用随程序携带的 `conpty.dll` 与 `OpenConsole.exe`。pi 全屏模式等先请求鼠标、后切输入模式的程序，滚轮不再被转成方向键翻输入历史，可正常滚动会话；设置环境变量 `QINGCODE_INBOX_CONPTY=1` 可退回系统 ConPTY。
- **本机终端宿主按构建区分**：升级后新开的终端进入新版宿主（新版 ConPTY 等修复立即生效），升级前打开的终端仍留在旧宿主里可正常接回、关闭，全部结束后旧宿主自动退出。
- **`Ctrl`+点击路径更可靠**：终端里 Claude Code 等程序持续重绘时，路径不再因为悬停链接在重绘间隙丢失而无反应，改为按松开鼠标那一刻的内容重新识别并打开。
- **手机接入终端更快**：手机尺寸与终端不同时，接入请求直接带上手机网格，电脑端当场改尺寸并在重绘告一段落后回复，省去两次往返和约 0.9 秒的空等；不重绘的普通 Shell 等待从 1 秒以上缩短到不超过 0.4 秒。需同时更新电脑端和 Android APK。
- **手机与项目列表**：手机全屏程序滑块新增「到底」按钮，自动下滑直到画面不再变化（最长 10 秒）；会话列表时间由「创建于」改为「活动于」；项目选择列表显示 SSH 连接名标签，并支持按连接名筛选。
- **远程连接编辑页**：默认回填本机已保存的 SSH 密码（以圆点遮挡），点眼睛即可查看。

配套远端 Server 版本为 `0.1.20`。完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.md)。
