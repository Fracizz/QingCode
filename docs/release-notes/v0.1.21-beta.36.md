## QingCode v0.1.21-beta.36

**Language / 语言:** [English](#english) · [中文](#中文)

<a id="english"></a>

### English

A beta after v0.1.21-beta.7 that focuses on automatic terminal reattachment after restart, per-connection terminal profiles and prewarm settings, remote Server update reliability, and a long round of terminal-list and mobile polish.

#### Highlights

- Terminals reattach automatically after startup: running terminals from every project are reattached in the background without switching projects or taking focus, with a global switch in Settings → Projects and Sessions (on by default). Connections that need a password, have an unconfirmed host fingerprint, or were disconnected manually are skipped. A single "Reattached N terminals" toast appears when reattachment finishes, and a quiet "Reconnecting terminals in the background…" hint shows when it starts.
- Terminal profiles are grouped per remote connection, can be copied across connections and imported; a connection's own default profile now takes precedence over the global default, and a global default scoped to another connection falls back to the ordinary terminal.
- Plain-shell prewarm counts are set per location (local Windows and each remote connection separately: Auto / Off / 1–8), and local CLI prewarming can keep 1–4 CLIs warm at once.
- Markdown preview supports in-page find; the find panel's close button is now vertically centered with its input.
- Ctrl+click on a path in an SSH terminal can open remote files outside the project root.
- Deleting an SSH connection also removes the remote projects and stored Server pairing credentials that reference it; orphan projects left behind by deleted connections are pruned automatically.
- Remote Server checks and updates are unified per connection: one progress card per connection ("Updating…" when replacing an older version), other projects on the same connection reuse the gateway verdict and prepare concurrently, and warm SSH channels are reused.
- The phone can recover unconfirmed terminal sessions.
- The prewarm badge shows Shell and CLI pools separately; double-click retries with a spinning indicator; ready/paused colors are softened to 75% and claimed terminals show the brand-colored ⚡ badge on desktop and mobile.
- Terminal list polish: fixed 16px icon slots, a larger host title, uniform 8px status markers, a 12px loading spinner, a calmer 2s rotation for running spinners (desktop and mobile), and a 15px local-project folder with fixed stroke width.
- Smaller installers from size-optimized release builds (with sqlx removed), a Rust target cache pruning policy, and the offline Server package now mirrored to Gitee. A fixed Android release signing key is configured for CI, so this beta ships a signed APK that can upgrade in place from the signed v0.1.21-beta.7 APK.

#### Fixes

- CLI prewarming no longer gets stuck at `cli_anchor_busy` when a Claude session already claimed an anchor; a timed-out ready check retries once before pausing, and prewarming recovers automatically after a forced Server update.
- Terminal view state is persisted from the xterm rendered screen, so reattaching after restart no longer overlaps or misaligns TUI output; inline TUIs are fully repainted once on reattach.
- Keyboard input typed while a terminal is being created or reattached is buffered and replayed when ready, avoiding "SSH terminal does not exist" during remote Server updates.
- Handing a terminal back from the phone resizes the desktop grid before changing the PTY size, so redraws no longer land in the narrow phone grid; mobile image attachment directories and SSH paste batch directories use local millisecond timestamps to avoid collisions.
- Linux remote terminal tabs no longer inherit the local default PowerShell 7; direct-gateway deployment checks the remote version when the local server has no manifest.
- Closing remote terminals on exit removes them from the terminal list, and failed reattach tabs release their pane binding. AI CLI multi-line paste still works when the terminal mode marker is missing.

The matching remote Server version is `0.1.21-beta.36`.

### 中文

v0.1.21-beta.7 之后的测试版，集中完成重启后自动接回终端、按连接管理终端配置与预热、远端服务更新稳定性，以及终端列表与手机端的一轮细节打磨。

#### 主要变更

- 启动后自动接回终端：所有项目里上次仍在运行的终端都会在后台接回，不切换项目、不抢焦点，可在「设置 → 项目与会话 → 启动时自动接回终端」关闭（默认开启）；需要密码、未确认主机指纹或已手动断开的连接会跳过。接回完成时右下角汇总提示一次「已接回 N 个终端」，开始接回时显示「正在后台接回上次的终端…」。
- 终端配置按远程连接分类，支持跨连接复制与导入；连接自己的默认配置优先于全局默认，归属其他分类的全局默认回落到普通终端。
- 普通 Shell 预热数量按位置单独设置（本机 Windows 与每条远程连接各自可选自动 / 不预热 / 1–8），本机 CLI 预热支持同时预热 1–4 个。
- Markdown 预览支持页内查找；查找面板关闭按钮与输入框垂直居中对齐。
- SSH 终端里 Ctrl+点击路径可打开项目根外的远端文件。
- 删除 SSH 连接时一并移除引用它的远程项目与 Server 配对凭据；引用已删除连接的孤儿项目自动清理。
- 远端服务按连接统一检查与更新：同连接只保留一张进度卡（替换旧版本时显示「更新中」），其余项目沿用网关结论并并发准备，SSH 通道复用。
- 手机端可恢复未确认的终端会话。
- 预热徽标分开显示 Shell / CLI 两个池，双击重新预热有转圈反馈；就绪/暂停状态色降到 75% 透明度，已领取的预热终端在电脑与手机端统一改用品牌色 ⚡。
- 终端列表打磨：图标固定 16px 槽、主机标题放大一级、状态标记统一 8px、加载转圈 12px、运行中转圈放慢到 2s/圈（手机端同步）、本地项目文件夹 15px 并固定线宽。
- 发布构建启用体积优化并去掉 sqlx，安装包更小；新增 Rust target 清理策略，Gitee 镜像补齐离线 Server 包。CI 已配置固定的 Android 发布签名密钥，本版随 Release 提供签名 APK，可从已签名的 v0.1.21-beta.7 APK 直接覆盖升级。

#### 修复

- CLI 预热不再被已领取的 Claude 会话卡在 `cli_anchor_busy`；预热就绪超时先自动重试一次，连续超时才暂停，强制更新 Server 后预热自动恢复。
- 退出时按 xterm 渲染画面持久化，重启接回后不再出现 TUI 画面叠帧错位；接回运行中的行内 TUI 时整屏重绘一次。
- 终端新建/接回在途时暂存键盘输入，就绪后补发，避免远端服务更新期间报「SSH 终端不存在」。
- 手机交还终端时先通知电脑端换回网格再改 PTY 尺寸，重绘不再落进手机窄网格；手机图片附件目录与 SSH 终端粘贴批次目录改用本地毫秒时间戳，避免互相覆盖。
- Linux 远程终端标签不再沿用本机默认的 PowerShell 7；直连网关部署时对无清单的本地服务端先核对远端版本。
- 退出时结束远程终端后从终端列表移除，接回失败标签不再残留窗格绑定；终端模式标记丢失时 AI CLI 仍可整段接收多行粘贴。

配套远端 Server 版本为 `0.1.21-beta.36`。
