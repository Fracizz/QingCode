### English

The stable release after v0.1.20, rolling up the whole 0.1.21 beta line: terminals reattach automatically after restart, prewarming and terminal profiles are configured per host and connection, remote Server updates are more reliable, and the terminal list, editor, and mobile workbench receive a long round of polish. This release becomes the version used by in-app update checks.

Windows requires WebView2; unsigned macOS builds may need right-click → Open on first launch. For updating a remote Server without internet access, see [Offline Server update](https://github.com/Fracizz/QingCode/blob/master/docs/server-offline-update.md). The Android APK uses the same release signing key as the v0.1.21 beta builds, so phones can upgrade in place; update both the desktop app and the APK to get every fix.

#### Highlights

- **Automatic terminal reattachment**: terminals still running last time are reattached in the background for every project after startup, without switching projects or taking focus, with a global switch in Settings → Projects and Sessions (on by default). Connections that need a password, have an unconfirmed host fingerprint, or were disconnected manually are skipped. A quiet hint appears while it starts and a single "Reattached N terminals" toast fades when it finishes.
- **Prewarming per host and connection**: independent local/remote switches, plain-shell counts per location (Auto / Off / 1–8) and 1–4 local CLIs prewarmed at once; the terminal list host header shows ready/target pool counts, and the badge separates the Shell and CLI pools with a double-click retry. Timed-out ready checks retry once, then automatically retry again after five minutes, with the stuck step recorded for diagnostics.
- **Terminal profiles per connection**: profiles are grouped per remote connection, can be copied across connections and imported; a connection's own default profile takes precedence over the global default, and a profile scoped to another connection falls back to the ordinary terminal.
- **Remote Server reliability**: checks and updates are unified per connection with one progress card, shared gateway verdicts for other projects, reused warm SSH channels, and parallel preparation. Deleting an SSH connection also removes the remote projects and stored Server pairing credentials that reference it; orphan projects are pruned automatically.
- **Terminal and editor**: Ctrl+click on a path in an SSH terminal can open remote files outside the project root; Markdown preview supports in-page find; the find panel's close button aligns with its input; keyboard input typed while a terminal is being created or reattached is buffered and replayed; AI CLI multi-line paste still works when the terminal mode marker is missing.
- **Mobile**: unconfirmed terminal sessions can be recovered, newly created CLI-configured terminals in local projects claim the local CLI pool, handing a terminal back resizes the desktop grid before changing the PTY size, and the mobile workbench refreshes projects and connections once when switching tabs.
- **Smaller installers and signed APK**: size-optimized release builds with sqlx removed, a Rust target cache pruning policy, the offline Server package mirrored to Gitee, and a fixed Android release signing key in CI so every release ships a signed, in-place-upgradable APK.
- **Polish**: terminal-list icon slots, host title, status markers and spinners (running spinners now rotate every 2 seconds on desktop and mobile); multi-device Git sync "cannot fast-forward" errors now show one short reason instead of a file list and instructions.

The matching remote Server version is `0.1.22`. Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.en.md).

### 中文

v0.1.20 之后的稳定版，汇总 0.1.21 测试线：启动后自动接回终端、按主机与连接独立配置预热与终端配置、远端服务按连接统一更新，以及终端列表、编辑器与手机端的一轮打磨。本版本也是应用内在线更新检查使用的版本。

| Windows ARM64 便携 | `QingCode_0.1.22-windows-arm64.exe` |

#### 主要变更

- **重启后自动接回终端**：所有项目里上次仍在运行的终端都会在后台接回，不切换项目、不抢焦点，可在「设置 → 项目与会话 → 启动时自动接回终端」关闭（默认开启）；需要密码、未确认主机指纹或已手动断开的连接会跳过。开始接回时显示「正在后台接回上次的终端…」，完成时右下角汇总一次「已接回 N 个终端」并自动消失。
- **按主机与连接独立预热**：本机 / 每条远程连接各有独立开关，普通 Shell 预热数量按位置单独设置（自动 / 不预热 / 1–8），本机 CLI 预热支持同时预热 1–4 个；终端列表主机标题显示就绪/目标数量，徽标分开显示 Shell / CLI 两个池并支持双击重试。就绪超时先自动重试一次，暂停 5 分钟后再次自动重试，并记录卡住步骤供诊断。
- **终端配置按连接分类**：配置按远程连接分组，支持跨连接复制与导入；连接自己的默认配置优先于全局默认，归属其他分类的全局默认回落到普通终端。
- **远端服务更稳**：按连接统一检查与更新，同连接只保留一张进度卡，其余项目沿用网关结论并并发准备，SSH 通道复用；删除 SSH 连接时一并移除引用它的远程项目与 Server 配对凭据，引用已删除连接的孤儿项目自动清理。
- **终端与编辑器**：SSH 终端 Ctrl+点击路径可打开项目根外的远端文件；Markdown 预览支持页内查找，查找面板关闭按钮与输入框对齐；终端新建/接回在途时暂存键盘输入并补发；终端模式标记丢失时 AI CLI 仍可整段接收多行粘贴。
- **手机端**：可恢复未确认的终端会话；在本机项目新建 CLI 配置终端时领取本机 CLI 预热；交还终端时先换回电脑网格再改 PTY 尺寸，避免画面错位叠帧；切页时静默刷新一次项目与连接状态。
- **更小的安装包与签名 APK**：发布构建启用体积优化并去掉 sqlx，新增 Rust target 清理策略，Gitee 镜像补齐离线 Server 包；CI 配置固定 Android 发布签名密钥，每个 Release 都提供可覆盖升级的签名 APK。
- **细节打磨**：终端列表图标槽、主机标题、状态标记与转圈统一样式（运行中转圈放慢到 2s/圈，手机端同步）；多端同步「无法快进」的错误提示改为一行简短原因，不再列出文件与操作建议。

配套远端 Server 版本为 `0.1.22`。完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.md)。
