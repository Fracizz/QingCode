## QingCode v0.1.23

**Language / 语言:** [English](#english) · [中文](#中文)

<a id="english"></a>

### English

The stable release after v0.1.22, rolling up the 0.1.21-beta.52 beta line: phone-side connection pairing by copy/paste, a redesigned settings page and shortcut-bar manager, a centered Markdown update dialog, much steadier text input, a remote hardware overview, more accurate Git multi-device sync, and a terminal-output IPC encoding benchmark. This release becomes the version used by in-app update checks.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.23-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.23-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.23-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.23-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.23-macos-arm64.dmg` / `.zip` |
| Android 8.0+ (companion remote terminal) | `QingCode_0.1.23-android.apk` |
| Offline Server package | `QingCode_0.1.23-servers.zip` |

Windows requires WebView2; unsigned macOS builds may need right-click → Open on first launch. For updating a remote Server without internet access, see [Offline Server update](https://github.com/Fracizz/QingCode/blob/master/docs/server-offline-update.md). The Android APK uses the same release signing key as the v0.1.21 beta builds, so phones can upgrade in place; update both the desktop app and the APK to get every fix.

#### Highlights

- Copy connection details (including the saved password) on the desktop and paste them on the phone to import and pair the connection automatically.
- The phone's shortcut bar now only holds user-defined keys (built-in keys were removed from the desktop bar too); the manager lists a delete button for each custom key, keys are rendered as keycaps with emphasized modifier prefixes, and narrow screens no longer wrap key labels character by character.
- Phone settings are now an icon list with card borders and rounded corners in the light theme; multi-line inputs stack their buttons vertically only when widening is not enough, trailing spaces stay visible and wrap, and the project page shows the remote connection count.
- The phone update prompt is a centered dialog that renders release notes as Markdown and drops the desktop download table.
- The remote connection overview shows CPU core count, nominal frequency, total memory and live usage; remote Server status is aggregated per connection and SCM errors no longer raise duplicate toasts.
- Git multi-device sync: the branch column reflects a branch switch immediately, and a "cannot fast-forward" error is now one short reason instead of a file list and instructions.
- Paused CLI prewarm pools retry automatically after five minutes, with the stuck step recorded in the timeout diagnostic.
- A terminal-output IPC encoding benchmark (front-end and Rust) was added to evaluate whether base64 event payloads are a bottleneck, and `LineIcon` keeps icons and text aligned in single-line hints such as toasts.

#### Fixes

- Long-pressing on the phone no longer triggers both the native text selection and the terminal's own selection; multi-line input no longer switches layout per keystroke (which made IMEs swallow spaces).
- Tapping a settings row no longer flashes the WebView highlight; custom-key dialogs put their button label first and no longer lag while typing; nested dialogs and collapsing the shortcut bar no longer flicker.
- The connection page's settings button enters with the page, appears only on that page, and no longer covers the project page refresh button; home sessions keep the sidebar project order instead of jumping to the top after use.
- Project group outlines no longer cover the sticky header, folder icons align with the first line of project names, "result unknown" hints collapse after being opened, and probing dots breathe once slowly instead of pulsing.
- The desktop no longer shrinks terminal columns when following a phone grid; old local server binaries without a manifest no longer hide the current version and automatic download.
- The experiment that merged intermediate TUI frames after burst input/paste on the phone was reverted after it caused regressions; a safer approach will follow.

The matching remote Server version is `0.1.23`. Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.en.md).

### 中文

v0.1.22 之后的稳定版，汇总 0.1.21-beta.52 测试线：手机端连接配对、设置页与快捷键栏、更新弹窗和输入体验的一轮打磨，远程连接概览补充硬件与实时占用，Git 多端同步更准确，并新增终端输出 IPC 编码基准。本版本也是应用内在线更新检查使用的版本。

#### 下载

| 平台 | 文件 |
|------|------|
| Windows x64 便携 | `QingCode_0.1.23-windows-x64.exe` |
| Windows x64 安装包 | `QingCode_0.1.23-windows-x64-setup.exe` |
| Windows ARM64 便携 | `QingCode_0.1.23-windows-arm64.exe` |
| Windows ARM64 安装包 | `QingCode_0.1.23-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.23-macos-arm64.dmg` / `.zip` |
| Android 8.0+（配套远程终端） | `QingCode_0.1.23-android.apk` |
| 离线 Server 包 | `QingCode_0.1.23-servers.zip` |

Windows 需安装 WebView2；macOS 未签名构建首次可能需要右键 → 打开。远端或本机无法联网时更新 Server，见 [离线更新远端 Server](https://github.com/Fracizz/QingCode/blob/master/docs/server-offline-update.md)。Android APK 与 v0.1.21 测试版使用同一发布签名密钥，手机可直接覆盖升级；请同时更新电脑端与 APK 以获得全部修复。

#### 主要变更

- 电脑端支持复制含密码的移动连接信息，手机端粘贴后自动导入并配对。
- 手机端快捷键栏管理列表直接提供自定义键删除按钮；自定义按键预设改为键帽样式、修饰键前缀用强调色区分；电脑端终端快捷键栏不再提供内置键，只保留用户自定义键。
- 手机端设置页改为图标列表式，浅色主题分组显示卡片边缘与圆角；输入框多行时按钮竖排、行尾空格可见并折行，只有加宽后仍需多行才竖排；项目页顶部显示远程连接数。
- 手机端更新提示改为居中弹窗，更新说明按 Markdown 渲染并去掉桌面下载表。
- 远程连接概览显示远端 CPU 核心数、标称主频、内存总量与实时占用；远端服务状态按连接汇总显示，源代码管理错误不再重复弹出提示。
- Git 多端同步设置页的分支列及时反映切换后的分支；「无法快进」提示改为一行简短原因，不再列出文件与操作建议。
- CLI 预热就绪超时暂停后 5 分钟自动重试，超时诊断记录卡住步骤。
- 新增终端输出 IPC 编码前后端基准（前端脚本与 Rust 侧用例），用于评估 base64 事件负载是否为瓶颈；新增 `LineIcon` 组件，让 Toast 等单行提示的图标与文字水平对齐。

#### 修复

- 手机端长按不再同时触发系统原生选择与终端自带选择；多行输入时不再逐键切换布局，避免输入法吞掉空格。
- 手机端设置行点击不再闪现 WebView 默认高亮；自定义键弹窗按钮名称移到最上方并修复输入卡顿；快捷键栏管理与嵌套弹窗操作更流畅，收起快捷键栏不再闪屏。
- 手机端连接页顶栏设置按钮与页面同步入场、只在连接页显示，不再提前出现并压住项目页刷新按钮；首页会话沿用侧栏固定项目顺序，使用后不再自动排到最上面。
- 手机端项目页分组描边不再盖住吸顶标题，组头文件夹图标与项目名首行对齐，「结果未知」提示点开查看后可收起，延迟探测圆点改为缓慢呼吸一次。
- 电脑端跟随手机网格时不再缩小终端列数；无清单的本地旧版服务程序不再遮蔽当前版本与自动下载。
- 手机端「整段输入或粘贴后合并 TUI 中间帧」的实验因引发回归已回滚，后续改用更稳妥的方案。

配套远端 Server 版本为 `0.1.23`。完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.md)。
