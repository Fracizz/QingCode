<a id="english"></a>

### English

Multi-platform builds (unsigned macOS: right-click → Open the first time). WebView2 required on Windows.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.7-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.7-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.7-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.7-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.7-macos-arm64.dmg` / `.zip` |

#### Highlights

- **Navigation**: heuristic / semantic Go-to-Definition, definition preview, usage grouping; back/forward and Ctrl+P
- **Source Control**: fetch, ahead/behind badges, sync relative times; clearer Git error summaries
- **Terminal**: quad layout with per-pane sessions; double-click close no longer starts rename
- **Editor**: Vue support; session cache settings; unified tab chrome
- **Startup**: splash stays visible ~500ms so the brand logo is readable

Full notes: [CHANGELOG.en.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.en.md).

### 中文

多平台构建（macOS 未签名：首次请右键 → 打开）。Windows 需安装 WebView2。

#### 下载

| 平台 | 文件 |
|------|------|
| Windows x64 便携 | `QingCode_0.1.7-windows-x64.exe` |
| Windows x64 安装包 | `QingCode_0.1.7-windows-x64-setup.exe` |
| Windows ARM64 便携 | `QingCode_0.1.7-windows-arm64.exe` |
| Windows ARM64 安装包 | `QingCode_0.1.7-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.7-macos-arm64.dmg` / `.zip` |

#### 主要变更

- **代码导航**：启发式 / 语义定义跳转、定义预览与用法分组；前进回退与 Ctrl+P
- **源代码管理**：检查更新、ahead/behind 计数、同步相对时间；Git 错误摘要更清晰
- **终端**：田字四终端与按窗格独立会话；双击关闭不再误触发重命名
- **编辑器**：Vue 支持、会话缓存配置；统一标签样式
- **启动**：开屏最短约 500ms，避免品牌 Logo 一闪而过

完整说明见 [CHANGELOG.md](https://github.com/Fracizz/QingCode/blob/master/CHANGELOG.md)。
