### English

Multi-platform builds (unsigned macOS: right-click → Open the first time). WebView2 required on Windows.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.8-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.8-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.8-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.8-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.8-macos-arm64.dmg` / `.zip` |

#### Highlights

- **Search**: longer debounce while typing; Enter searches immediately; short queries skip content scan
- **Run configs**: optional project session restore switch
- **Editor**: unified selection highlight that keeps syntax colors
