<a id="english"></a>

### English

Multi-platform builds (unsigned macOS: right-click → Open the first time). WebView2 required on Windows.

#### Downloads

| Platform | File |
|----------|------|
| Windows x64 portable | `QingCode_0.1.9-windows-x64.exe` |
| Windows x64 installer | `QingCode_0.1.9-windows-x64-setup.exe` |
| Windows ARM64 portable | `QingCode_0.1.9-windows-arm64.exe` |
| Windows ARM64 installer | `QingCode_0.1.9-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.9-macos-arm64.dmg` / `.zip` |

#### Highlights

- **Source Control**: multi-remote URL panel, Ctrl+A select all in change lists, stable commit history on first open, aligned stage/unstage action column
- **Layout & window**: terminal docked on the right; title-bar drag via WebView2 `app-region`; large-file preview improvements
- **Windows I/O**: configurable text read modes (auto / compatible / native) for DLP or encrypted files
- **Navigation & UI**: usage-first go-to-definition; top-bar Git count badges; About panel with copyable version info; status-bar memory tooltip consolidates project terminal usage

### 中文

多平台构建（macOS 未签名：首次请右键 → 打开）。Windows 需安装 WebView2。

#### 下载

| 平台 | 文件 |
|------|------|
| Windows x64 便携 | `QingCode_0.1.9-windows-x64.exe` |
| Windows x64 安装包 | `QingCode_0.1.9-windows-x64-setup.exe` |
| Windows ARM64 便携 | `QingCode_0.1.9-windows-arm64.exe` |
| Windows ARM64 安装包 | `QingCode_0.1.9-windows-arm64-setup.exe` |
| macOS Apple Silicon | `QingCode_0.1.9-macos-arm64.dmg` / `.zip` |

#### 主要变更

- **源代码管理**：多远程 GIT 地址展示、变更/待提交列表 Ctrl+A 全选、首次打开历史稳定加载、暂存/取消暂存操作列对齐
- **布局与窗口**：终端移至右侧；标题栏 WebView2 拖动；大文件预览优化
- **Windows 读取**：文本读取模式（自动 / 兼容 / 原生），便于 DLP 或加密文件
- **导航与界面**：转到定义优先用法分组；顶栏 Git 数量角标；关于面板可复制版本信息；状态栏内存提示合并项目终端占用
