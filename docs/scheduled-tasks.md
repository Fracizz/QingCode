# QingCode Next 定时任务

电脑版在当前项目的工具栏或命令面板打开「定时任务」，也可以按 `Ctrl+Shift+Y`。任务支持每天、工作日和每周，按任务保存的时区运行。表单预览接下来三次触发。目标机可以是本机、SSH 或 TLS 直连服务器。

## 启用和运行

- 仅受信任的项目可以保存、启用或立即运行任务。新任务默认暂停，保存时可勾选启用。立即运行需要确认，保留原周期，两种方式都会消耗用户本人的 Agent 额度。
- 每次运行创建独立的持久会话。Codex 使用原生只读沙箱和用户审批，Claude 使用原生计划模式，pi 按自身配置执行工具。pi 没有逐次审批，保存任务前须确认。
- 运行记录显示错过、跳过、等待处理、成功、失败、中断及限额状态，保留最近 50 次。出现审批、提问或扩展交互时，从记录打开会话处理。Agent 无响应或运行超时后由 daemon 尝试中断当前轮次。
- 暂停任务停止后续触发。移除项目或撤销信任时，目标机暂停关联任务并尝试中断该项目进行中的定时运行。已知有任务的项目需要先连上目标才能撤销信任或移除。删除任务会清除其运行记录，Agent 会话仍保存在目标机。

## 调度与恢复

任务与运行记录在目标机的 `stateDir/schedules.json`。同一目标同时最多运行一项定时任务。到期槽位与运行记录一次性落盘后才发送提示词。正常运行时允许 90 秒以内的调度延迟，超过后记为错过。夏令时回拨的重复时刻只取第一次，春季跳过的时刻不补跑。

有启用任务时，目标 daemon 会在客户端断开后继续运行。目标机重启后，重新连接拉起 daemon，未完成的运行记为中断，错过的触发跳过。触发限额时暂停同一目标、同一 Agent 的定时活动，重置时间可用时在重置后的下一次计划时间恢复，缺少重置时间时需用户重新启用。

任务保存当时的目标 Agent 路径及配置目录。对话通道有不同的活动配置时，定时任务不会切换配置。更新 Agent 配置后，重新保存对应任务。
