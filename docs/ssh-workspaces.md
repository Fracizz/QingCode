# SSH 工作区

QingCode 的 SSH 工作区直接在 Tauri 后端建立 SSH/SFTP 连接，不要求远端安装 QingCode Agent。

## 使用方式

在项目选择器中点击 `+`，选择 `SSH`，填写主机、端口、用户名、认证方式和远程绝对路径。首次连接会展示服务端 SHA-256 主机指纹，用户确认后才会认证并打开项目。

- 私钥路径和确认过的主机指纹保存在本机 SQLite。
- 密码与私钥口令只保留在当前进程内，不写入项目、设置文件或数据库。
- 推荐使用无口令私钥；这类项目可在应用重启后自动重连。
- 密码或加密私钥在应用重启后需要重新连接并输入凭据。

## 当前能力

- 通过 SFTP 浏览、读取、编辑、新建、重命名和删除远程文件。
- 文件名搜索；内容搜索由远端 `rg` 执行。
- 远程 PTY 终端和 Linux shell 任务。
- 基础 Git 状态、暂存、取消暂存、提交、拉取、推送和获取。
- 多项目搜索可以混合本地项目和 SSH 项目。

所有远程资源使用内部 `ssh://<connection-id>/<absolute-path>` 标识。后端只接受已注册项目根目录内的资源；写入和命令执行还要求工作区处于信任模式。SFTP 操作会解析真实路径并拒绝通过符号链接越出项目根目录。

## 当前边界

- SSH 工作区不启动本地 Tree-sitter 索引，定义跳转、引用查找和工作区符号等语义导航不可用。
- 内容搜索要求远端安装 `ripgrep`（`rg`），Git 功能要求远端安装 `git`。
- 当前面向 POSIX/Linux 远端；不支持远端 PowerShell 或 BAT 任务。
- WSL 直连工作区尚未接入；可先通过 WSL 内的 SSH 服务使用同一 SSH 工作区能力。
- 尚未提供远程扩展、端口转发、SSH Agent 转发和连接配置管理页。
