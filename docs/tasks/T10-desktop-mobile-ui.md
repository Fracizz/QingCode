# T10 电脑端"手机连接"设置界面

范围：只改 `apps/desktop/src/renderer/**`（新增组件为主，App 里只加入口）。依据：`docs/mvp.md` §9.2、§9.3；backend `mobile.*` 方法（T9）。

- 左栏底部"手机连接"入口 → 设置面板：启用开关、端口、配对密码（显示/隐藏，6–20 位校验）、对外地址列表（增删，`host:port` 校验，旁注"frp/端口转发等公网地址，填手机实际访问的地址和端口"）、局域网地址列表、证书指纹（4 位分组显示）+"重新生成"（二次确认，说明会解除所有配对）。
- "复制连接信息"：先选地址（局域网/对外地址），调用 `mobile.connectionInfo` 后写入剪贴板（`navigator.clipboard.writeText`），提示"含配对密码，请只发给自己"。
- 已配对设备：名称、配对时间、最近在线/IP，"撤销"。
- 运行状态与错误（端口被占用等）。

验收：`pnpm --filter @qn/desktop typecheck`、相关纯逻辑单测、`build` 成功、`--smoke` 仍为 0。
