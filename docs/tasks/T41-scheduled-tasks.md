# T41 桌面定时任务

在电脑版管理定时任务。目标机的 `qn-server` 负责调度，用现有 Codex、Claude 或 pi 通道创建独立会话。范围与规则见[定时任务](../scheduled-tasks.md)。

## 验收

- 选中本机、SSH 或直连目标上的已信任项目后，从工作区工具栏、命令面板或 `Ctrl+Shift+Y` 打开定时任务。创建、编辑、暂停、启用、立即运行和删除均有明确反馈。历史可打开原会话。
- 每次运行新开会话，Codex 确认原生只读权限后才发提示词，Claude 使用原生计划模式，pi 保存前由用户确认其工具没有逐次审批。
- 定时触发前先写运行记录和下一次触发时间。客户端断开后 daemon 继续负责执行，用户重连可处理审批。daemon 重启时结束未完成的记录并跳过错过的时间，升级保护覆盖 Agent 启动阶段。
- 时区按任务设置。覆盖跨时区、夏令时、重叠触发、审批与超时、限额和撤销信任。以假 Agent 完成三种协议链路测试，Windows 及 Linux SSH 真机单独验收。
