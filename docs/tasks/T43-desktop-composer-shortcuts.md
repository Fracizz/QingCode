# T43 电脑端输入框快捷标签

在电脑端主对话里，用一个标签填入常用文字。每个标签可单独开启一键发送，适用于「用 review 技能检查当前改动」「继续」「只分析，先别改代码」这类经常输入的内容。

## 入口与配置

- 在输入框正上方放一行圆角标签，与输入框左边对齐。标签行跟随输入框布局，避免遮住消息、附件和引用。空间不足时把剩余标签收进「更多」，没有标签时由「设置 → 通用 → 输入框快捷标签」提供添加入口。
- 每个标签保存显示名称、要填入的文字和「一键发送」开关。名称和文字必填，文字支持多行。用户可以新增、编辑、删除、调整顺序。设置保存在当前电脑，供各项目和 Agent 的主对话共用。
- 一键发送默认关闭。开启后的标签用发送图标区分，悬停或键盘聚焦时说明本次会填入、发送还是排队。标签支持 `Tab` 聚焦和 `Enter` 或空格触发。

## 点击行为

| 场景 | 结果 |
| --- | --- |
| 一键发送关闭 | 在光标处插入文字。有选区时接在选区末尾，未记录光标位置时追加到末尾。保留已有内容，焦点回到输入框。 |
| 一键发送开启，草稿为空，当前可发送且会话空闲 | 直接提交标签文字。新对话沿用现有首条消息建会话的流程。 |
| 一键发送开启，草稿为空，当前可发送且会话运行中或正在压缩 | 把标签文字放入当前会话的发送队列，沿用队列的顺序和反馈。 |
| 一键发送开启，已有草稿，或当前可编辑但暂时无法发送 | 只插入文字。正文、附件、引用或已填技能任意一项存在，都视为已有草稿。 |
| 输入框不可编辑 | 禁用快捷标签。 |

标签内容按普通文字保存和填入。可以写技能名、提示词或多行说明，提交时沿用手动输入相同内容的规则。发送或入队失败时保留填入的文字和错误反馈，供用户编辑或重试。一键发送提交期间暂时禁用触发该次提交的标签。

## 实施与验收

- 在桌面 `ChatPanel` 接入 `Composer`，复用桌面偏好设置、现有草稿和发送队列。首版范围为电脑端主对话，交付时登记到[电脑版与手机版能力对齐](../client-capabilities.md)。
- 验证新增、编辑、排序、删除及重启恢复。验证新对话、已有会话、窄窗口「更多」菜单及键盘触发。
- 验证文字与技能名按普通文本填入，多行内容保留原有换行。有正文、仅附件或仅引用时，开启一键发送的标签也只填入。
- 验证空草稿一键发送、运行中排队、断线或发送失败时保留草稿，以及连续点击不会重复提交。实现后运行桌面类型检查与对应的 Vitest 测试。
