# 终端长文本、附件与内容导出

终端内容区右键提供「换行」「编辑长文本」「复制当前屏幕」「导出终端内容…」。操作绑定右键所在终端，不依赖当前全局活动窗格。

## 换行

终端获得焦点时，`Ctrl+Enter`（macOS 同时支持 `Cmd+Enter`）向当前 PTY 发送 LF（`\n`，等价于 `Ctrl+J`），不会附加用于提交的 CR。右键「换行」执行同一操作，仅在终端可写时启用。

是否显示为输入中的新行由当前程序的按键绑定决定：Claude／OpenCode 等 Agent 可以绑定为换行，普通 Shell 仍可能把 LF 当作确认当前命令行。终端已退出、正在启动或正在重连时不发送；按键长按不会连续插入多行。

`Shift+Enter` 在 Agent 或全屏 TUI 中发送同样的 LF，普通 Shell 中保持原样（发送 CR）。判定依据为程序开启的备用屏、鼠标上报或焦点上报，以及 Claude／Codex／OpenCode 的窗口标题；shell 集成报告已回到提示符时不再相信可能残留的标题。可在「终端 › 集成: Shift+Enter 换行」关闭。

## 文件路径与超链接

按住 `Ctrl`（macOS 为 `Cmd`）点击终端输出中的文件路径，在编辑器打开并定位。普通点击仍用于聚焦、选择或交给 TUI。支持 `a.ts:12:3`、`a.ts#L12-L20`、`a.cs(12,3)`、`File "a.py", line 12`、`@a.ts#L5`，以及引号内带空格的绝对路径或 `./` 路径。只识别能看出是文件的文本：目录必须带扩展名或是 `Makefile` 等已知文件名，单个文件名还须是常见源码扩展名或带行号。自动折行的路径可以识别；程序自己插入换行（如 Claude Code 按宽度断行）的不能。相对路径或单个文件名在当前目录和项目根下找不到时，会在项目内按完整文件名搜索（遵循搜索排除设置）：只有一个结果直接打开，多个结果或结果过多时打开快速打开让你选择。绝对路径不搜索。

相对路径依次按终端启动目录和项目根目录解析，同时尝试去掉 `git diff` 的 `a/`、`b/` 前缀和 Alt+C 引用的项目名前缀。终端内 `cd` 后的目录不会跟踪。路径按项目所在的域解释，不跨域映射：本机 Windows 项目不打开 `/usr/...`，WSL 项目把 POSIX 绝对路径放进所在发行版，SSH 项目只打开项目根目录内的 `ssh://` 资源。找不到文件时提示，不新建标签。

OSC 8 超链接同样需要 `Ctrl`／`Cmd` 点击：`file:` 与 `vscode://file/...`、`cursor://file/...`、`windsurf://file/...` 按上述规则打开（Codex 默认输出 `vscode://` 链接），其他非网页协议不打开。网页链接的文字与实际地址不同时先确认。

## 终端身份

本地与远程终端都注入 `TERM_PROGRAM=QingCode`、`TERM_PROGRAM_VERSION` 和 `QINGCODE_TERMINAL_ID`，WSL 通过 `WSLENV` 转发。SSH 兼容模式写入启动命令；Windows 远端的兼容模式无法追加，不注入。

## 长文本

「编辑长文本」打开非模态浮动面板（不使用 ModalOverlay），不改变底层终端尺寸，也不额外通知 PTY resize。面板无遮罩、不模糊背景，终端在其下仍可滚动、选择和复制，方便对照编写；默认宽 840px、高度约为视口的 70%（上限 700px）；标题副行只显示目标终端，名称放不下时截断并悬停显示全文；附件与提交说明放在输入框的占位提示中，开始输入后不再占用空间。拖动标题栏移动（标题栏始终保留在视口内），右下角调整大小，位置与尺寸记忆在 `localStorage` 的 `qingcode:terminal-composer-rect`，双击标题栏恢复默认居中。Escape 仅在焦点位于面板内时关闭，焦点在终端时照常发给 Claude／OpenCode；再次右键「编辑长文本」会把焦点带回面板。所属终端被切到后台（换标签、项目或布局）时面板随之隐藏、草稿保留，切回后重新出现。拖入文件时只有落在面板上的进入草稿，落在终端上的仍按终端粘贴规则处理。Enter 在文本框中换行，不提交终端。草稿按终端 ID 在内存中隔离，关闭浮层或切换项目后保留；填入成功、关闭终端或重新启动会话后清除；应用重启不恢复草稿。

「填入终端」通过 xterm 的粘贴入口填入原始文本，不额外发送 Enter。多行文本要求目标程序已启用 bracketed paste；未启用时保留草稿并提示使用「复制」后手动粘贴，避免普通 Shell 将换行直接解释为执行。目标正在启动、重连或已结束时不填入。

## 附件

终端内容区和长文本框均支持粘贴图片／文件；长文本框还提供「添加附件」文件选择器，并支持拖入文件。附件在草稿光标处插入文件路径，最终由 Claude／OpenCode 自身读取材料。

- 路径文本（如 `D:/code/django`、带引号路径或 `file://` 文本）按原文粘贴，不会因本机路径存在而上传。只有剪贴板中的文件／图片、拖入文件或显式选择附件才按附件处理。
- 本机按实际 Shell 引用路径；Linux（包括以 Linux 使用的 WSL 环境）使用 POSIX 路径与引用规则，不增加基于前端 Windows 身份的 WSL 路径转换层。Windows 原生 `wsl.exe` 中的跨系统路径映射不在本次新增范围内。
- 浏览器 File／截图字节保存到新建的私有临时目录，保留原始二进制数据。Linux／macOS 系统剪贴板 RGBA 图片转换为 PNG；Windows 复用已有 PNG／DIB 读取。
- SSH 附件复用现有上传队列，上传到项目内 `.qingcode/terminal-paste/<批次>/`，完成后使用远端路径。终端直接粘贴仍遵循「SSH 粘贴上传」设置；长文本框中显式添加附件会准备该附件。
- 单个附件最多 100MB。临时文件不会在填入后立即删除，以便 AI 稍后读取；远程文件可通过已有「清理远程粘贴文件」操作清理。
- 异步附件准备绑定原终端和进程代次，关闭／重启后不向新进程填入。准备失败时保留草稿并显示错误。

## 复制与导出

- 「复制当前屏幕」：复制右键打开时该窗格当前可见行的文字；向上滚动后复制所见位置。不改选区、滚动位置、输入或进程状态。
- 「导出终端内容…」：在执行时读取当前活动缓冲区内保留的文字，然后打开本机保存对话框，保存为 UTF-8 TXT。SSH 终端也保存到本机所选位置。
- 按显示字符提取，保留缩进与内部空行，合并自动折行，移除行尾填充和末尾空白行；不输出 ANSI 控制指令。
- 全屏 TUI 的 alternate buffer 通常只有当前画面。被程序覆盖、清除或被 scrollback 上限淘汰的内容无法恢复，因此导出不能视为完整 AI 对话记录。
- 不提供「导出当前可见内容」或「复制已保留的全部内容」。

## 验收

Vitest 使用真实 xterm 检查滚动视口、中文折行、alternate buffer 重绘与 ANSI 去除，并检查草稿隔离、附件光标插入和目标会话失效。Rust 测试检查附件目录边界、二进制保真和 RGBA→PNG 后的像素内容。

完整 App 的 Web 测试复用生产终端、浮层与 Store，只模拟原生边界。附件字节仅保存在测试运行时内存；不能替代系统剪贴板、原生拖放、SSH 上传及真实 Claude／OpenCode 验收。真实 WebView2 缩放和拖动仍须按 `docs/terminal-resize.md` 验证。
