# QingCode Android

安卓版的界面与统一圆角规范见 [Android 设计规范](android/design.md)。

## APK 按需发布

本地 `pnpm package:exe` / `pnpm package:installer` 会检查 Android 输入文件和已生成 APK 的摘要。
有更新或 APK 缺失/损坏时构建 `release/QingCode_<版本>-android.apk`，并更新 `QingCode-Android.apk`；
无更新时保留原 APK 的版本和文件。仅桌面版本号变化不触发 APK 构建。
需要 `ANDROID_HOME` / `JAVA_HOME`，也支持本项目现有 `.dev/android-build/sdk` 工具目录；
缺少工具链时提示跳过。签名沿用已有本地密钥；缓存保存在 `.dev/android-build/package-state.json`。

Release 工作流以最近一个实际包含 APK 的公开发布版本（含预发布）为比较基准。
Android 源码、构建/版本脚本、打包图标、依赖锁文件或 APK 内置依赖声明变化时才重新打包；
仅桌面端或应用版本号变化时跳过 APK，继续使用最近发布的 Android APK。
首次发布会尝试构建；仍须配置固定发布签名密钥，缺少密钥时跳过 APK，不阻断桌面端发布。

Android 端是终端优先的远程控制器。手机可保存多台能通过局域网访问的 Windows QingCode，在「连接」中切换、重连、重命名、修改端口、重新配对或移除。每台电脑分别提供本机、WSL 和远端已信任项目，Windows 负责 SSH、Server 连接和凭据管理。

项目列表将连接名称、IP / 主机名与路径分行显示；同名项目可按来源区分，也可搜索连接名或地址。
「WSL」筛选对应电脑直接添加的 WSL 目录；通过名为 WSL 的远端连接访问的项目归入「远端」，显示例如「远端 · WSL · localhost」。首页继续终端和终端标题也保留来源信息。

## 配对和使用

1. 在 Windows QingCode 的「设置 → 功能 → Android 移动连接」填写端口和自定义 6–20 位密码，再保存并启用。Windows 自动监听局域网 IPv4 连接（含 Tailscale 等 `100.64.0.0/10` 地址）。密码可使用纯数字、纯字母或符号，无需组合，区分大小写；默认记住，可在电脑端显示或隐藏。启用后设置页显示配对二维码；电脑有多块网卡时可切换二维码使用的地址。
2. 在 Android 的「连接」中点「添加」，选择「扫码添加」扫描电脑上的二维码，或「粘贴配对链接」粘贴电脑端「复制配对链接」得到的 `qingcode://pair?...`。系统相机或其他扫码应用打开该链接时也会直接进入配对。二维码包含地址、端口和证书指纹，手机连接时自动核对指纹，不一致会停止配对；之后只需输入密码。也可以手动填写 IPv4、端口和密码直接连接，无需手动确认指纹；首次连接会自动记住电脑证书，后续证书变化时须重新扫码或粘贴配对链接。旧版单台电脑的配对会在升级后自动导入。
3. 从「终端」继续最近使用的项目，或在「项目」中按 IP、项目名、连接名或路径搜索并打开项目。终端顶部可新建和切换会话，右上角菜单可结束会话。若列表缺少项目，在桌面添加并信任后刷新。
4. 底部命令栏支持中文输入和粘贴，点击发送后执行。键盘按钮切换到逐键输入，适合交互式 CLI。快捷键栏竖屏为两排（参考 Termux），提供 Esc、Tab、`/ - |`、Ctrl / Alt、^C、方向键、Home、End、PgUp 和 PgDn；横屏或键盘弹出压缩视口时收为一排并可横向滑动。Ctrl / Alt 单击为一次性，双击锁定（按键变为实心），再点一次释放；方向键和翻页长按连发。Ctrl 可组合字母及 `@ [ \ ] ^ _ ?`，Alt 以 ESC 前缀发送，也可与方向键组合。
5. 手机短暂离线、切换主机或重开 App 时，Windows QingCode 继续托管会话。更新后的电脑端与 APK 接回时直接显示最新屏幕，再按序号接收后续输出，不再等待旧缓存逐块重放；Server 模式的远端屏幕快照也参与这一流程。

首页显示当前电脑状态、最近项目和最多三个快捷项目入口；离线时可直接重连。首页和项目页在顶部继续下拉即可刷新项目。项目页统一显示本机、WSL 和远端项目，不再使用环境分类；搜索栏吸顶，支持 IP、项目名、连接名及路径，无匹配结果时可一键清除搜索。
终端顶栏右侧可新建终端，有多个会话时才显示会话标签栏。右上角「终端会话」（竖屏为底部弹层，可下滑关闭）可调整并记住手机字号（11–20px）；快捷键 `^C` 直接发送 Ctrl+C，不受已锁定的修饰键影响。回看历史输出时点「回到最新」继续跟随输出。

终端底部和首页电脑状态显示「电脑 32 ms」，表示手机到当前电脑的认证请求往返耗时，包括需要时的连接建立，不包含电脑到远端和终端程序处理耗时。终端前台每 10 秒测量，首页等工作台页面每 30 秒测量；切到后台暂停，回到前台立即刷新。同一电脑的终端共用结果，失败、无结果或超过三个采样周期未更新时显示 `--`。连接详情显示测量范围和最近测量时间。旧版电脑不支持时显示 `--` 并提示更新电脑端，不影响其他功能；延迟探测失败不会触发业务重连。
键盘按钮可在实时输入与可编辑命令栏之间切换，空白命令栏点击发送表示回车；组词期间不会提交。切换会话保留各自的未发送草稿。

输入 Claude / OpenCode 的斜杠命令或技能时，点「/ 技能」打开实时键盘，输入名称，用 `↑` / `↓` 选择终端候选，「Tab 补全」补齐，最后点回车确认。也可以先在命令栏写 `/effort`：第一次发送只查看候选，再点回车确认。「Tab 补全」会先把单行草稿发送到终端，不附带回车；多行草稿保留在命令栏，普通命令仍直接发送并回车。技能和候选由当前终端程序提供。

横屏默认收起快捷键与补全入口，可在状态栏点「展开按键」，手动选择会保存在手机上。展开后，补全入口和命令栏并排；收起不会清除草稿或关闭实时键盘。状态栏的全屏按钮进入 Android [沉浸模式](https://developer.android.com/develop/ui/views/layout/immersive)，隐藏系统栏和应用顶栏，保留退出按钮及输入栏；边缘滑动可暂时唤出系统栏，Android 返回键先退出全屏，再次返回才离开终端。挖孔、圆角和软键盘仍保留必要避让。

在终端输出区单指上下滑动可查看历史输出；全屏终端程序的实体鼠标滚轮沿用桌面行为。横向滑动快捷键栏仍用于查看其他按键。

长按实时终端文字约半秒即可选中，拖动两端手柄可缩小选区或跨行选择；手柄拖至输出区上下边缘时可继续滚动本机已加载的终端缓冲。浮动工具栏提供「复制 / 全选 / 取消」，复制内容写入手机剪贴板，保留中文和换行；「全选」范围为当前 xterm 已加载缓冲。历史分页区域使用系统长按选字和复制。选字不会向 Shell、Claude 或 OpenCode 发送按键和鼠标输入；返回键先取消选区，再处理历史或全屏退出。屏幕旋转、终端网格变化或切换会话时清除旧选区。

终端向历史方向滑动至顶部后，自动衔接只读历史，无需按钮或图标。每次最多加载 120 行，接近当前页顶部时提前请求上一页并保持阅读位置；向最新方向滑回底部即可回到实时画面，也可使用原有「回到最新」或返回键。打开历史时先保留可见终端行，实时输出继续在后台接收。触摸移动逐帧合并，松手后减速滑动，再次触摸立即停止惯性；历史区域使用原生滚动。全屏 TUI 也可通过触摸滑动回看已有历史，实体鼠标滚轮仍交给程序处理，程序本身不追加松手惯性。

电脑端保留普通屏幕滚出的文本历史，上限为每个会话 1 MiB / 5000 行（先达到的限制生效）；它不是完整会话录像，不保存 TUI 的每次重绘。超出缓存会显示说明，Server 断线期间未传到电脑端的历史无法补齐。快照与历史分页需要同时更新电脑端 QingCode 和 Android APK；旧版电脑端仍按原协议重放。

## 配对的保存与撤销

扫码优先请求高清后置摄像头，设备支持时启用连续对焦；预览保留完整画面，识别先保留中央区域细节，再检查全画面。
请将二维码完整放在画面中央，等相机对焦；距离过近时稍微拉远手机。仍无法识别时，可使用「粘贴配对链接」。

- 配对长期有效。Windows 只保存令牌的 SHA-256 摘要，启用状态会被记住：重启电脑端 QingCode 后自动恢复监听，已配对的手机无需重新输入密码。自动启用失败（如端口被占用）时，设置页显示原因。
- 最多同时配对 8 台设备。设置页列出已配对的手机及在线状态，点「移除」即撤销该手机的授权，并结束它创建的终端。
- 「停止连接」关闭监听、结束所有手机终端，并在下次启动时保持关闭；已配对的手机会保留，重新启用后可直接连接。退出 QingCode 同样会结束手机终端，但不改变自动启用设置。
- 从手机移除连接只删除手机上的配对。需要撤销电脑端授权时，在 Windows 设置页移除该设备。
- 默认 TCP 端口为 `48764`，可自定义。密码长期有效，关闭连接或重启电脑端后自动填回，重新启用时留空也可沿用；旧版只保存校验值的密码继续有效，重新设置一次后才可显示。密码与证书私钥一起保存在仅当前用户可读的设置文件中，不会写进二维码或配对链接。更换密码需先停止连接；更换密码不影响已配对的手机。每个来源连续输错 5 次后须等待一分钟，全部来源合计每分钟最多尝试 20 次。

启用后可直接切换端口。新端口成功启用后旧端口停止监听；已配对的手机和正在运行的手机终端都会保留。在手机的「连接详情」中把端口改为新端口即可，无需重新配对，也可以重新扫码。若新端口被占用，原连接继续使用旧端口。Windows 防火墙中手动创建的规则由用户管理。

如果 Windows 防火墙阻止连接，在本机防火墙仅允许所需局域网来源访问所选端口。Windows 须保持在线，WSL 项目须存在对应的发行版，远端项目须能通过桌面已有的 SSH 或 Server 连接打开。打开远端项目时若电脑上弹出确认（如主机指纹），请在电脑上处理，手机最多等待 90 秒。工作区信任控制从哪里启动 Shell，Shell 使用其宿主账号的权限。

手机与电脑之间使用 HTTPS 长连接复用（空闲 10 秒内复用，电脑端 15 秒关闭空闲连接）；读取类请求遇到失效的复用连接会自动重试一次，输入、建终端等写操作不会自动重发。手机创建的终端输出只进入移动端缓冲，不广播给桌面窗口。手机终端不进入桌面的遗留终端列表，即使桌面重启后内存中的手机会话记录已丢失，也不能从桌面接回或通过遗留终端操作结束。

## 构建 APK

需要 Node 和仓库前端依赖、JDK 17、Android SDK Platform 35 和 Build Tools 35.x。在仓库根目录运行：

```powershell
pnpm.cmd install --frozen-lockfile
pwsh -NoProfile -File scripts/build-android.ps1 -SdkPlatform 'C:\Android\Sdk\platforms\android-35' -BuildTools 'C:\Android\Sdk\build-tools\35.0.1' -Jdk 'C:\Java\jdk-17'
```

设置 `ANDROID_HOME` 和 `JAVA_HOME` 后可省略这三个参数。输出为 `release/QingCode-Android.apk`。

- 版本号取自 `package.json`：`versionName` 与桌面一致，`versionCode` 由 `scripts/android-version.mjs` 推导（`major·10⁷ + minor·10⁵ + patch·10³ + 预发布序号`，正式版排在同号预发布之后），保证升级单调递增。
- 本地构建默认使用 Android 标准调试密钥库 `~/.android/debug.keystore`（不存在时自动生成，与 Android Studio 共用）。同一台电脑上的多次构建可以直接覆盖安装；换一台电脑构建的调试包签名不同，需要卸载后安装。
- 发布构建使用 `-Release` 和固定发布密钥库：`-Keystore`（或 `QINGCODE_ANDROID_KEYSTORE`）、`QINGCODE_ANDROID_KEYSTORE_PASSWORD`、`QINGCODE_ANDROID_KEY_ALIAS`，可选 `QINGCODE_ANDROID_KEY_PASSWORD`。口令通过环境变量传给 `apksigner`。
- Release CI 在配置了仓库 Secrets `ANDROID_KEYSTORE_BASE64`（发布密钥库的 base64）、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`（可选 `ANDROID_KEY_PASSWORD`）时构建 `QingCode_<版本>-android.apk` 并随 Release 发布、同步到 Gitee；未配置时跳过 APK 并给出警告，其余平台照常发布。密钥库一旦用于发布不可更换，否则已安装的手机无法覆盖升级。

系统需为 Android 8.0 或以上，并使用支持当前 xterm.js 的 Android System WebView。扫码需要相机权限，仅在点「扫码添加」时申请。Windows 配套版可用现有 `pnpm package:exe` 流程构建。

## 手机图片与快捷会话

终端顶部「+」提供「新建终端 / 新建 Claude / 新建 OpenCode」。后两项会新建独立会话，并在当前项目环境执行 `claude` / `opencode`；需要先在对应本机、WSL 或远端环境安装命令，原会话保留。

终端工具栏的图片按钮调用 Android 系统文件选择器，无需申请相册全盘权限。压缩等级会保存在手机，默认「中」：低 / 中 / 高压缩的最长边上限分别为 3072 / 2048 / 1280 像素，JPEG 质量分别为 92 / 80 / 60；按解码采样缩小，保留透明图片的 PNG 格式，并应用照片方向。原图支持 PNG / JPEG，压缩后的其他系统可解码图片也可发送。单张最大 8 MB。

图片发送到电脑后保存在独立临时附件目录；WSL 使用发行版的 `wslpath` 转换为 Linux 可读路径，远端项目复用桌面的 SSH / Server 文件传输并上传至项目 `.qingcode/terminal-paste/`。图片路径进入当前会话的命令草稿，可补充说明后提交。上传不会自动执行回车；取消或切换项目 / 会话后，迟到的结果不会写入其他草稿。超时不自动重发，远端如已收到文件，可按现有终端粘贴清理方式处理。

Android 30+ 由系统栏、刘海和键盘尺寸调整 WebView；圆角只增加底部控件的水平内边距，不再把整个页面按圆角半径抬高。底栏内容高 46px，上下各 4px，仍保留至少 44px 的触摸区域。
