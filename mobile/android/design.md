# QingCode Android 设计规范

本规范适用于本目录中的 Android 应用：`MainActivity.java`、`res/` 和 `web/`。WebView 界面样式以 `web/app.css` 为准；桌面端共用的品牌与交互原则见 [仓库设计规范](../../DESIGN.md)。新增和修改页面时沿用现有组件、颜色与圆角变量。

## 圆角

矩形控件和容器统一使用 **12 CSS px**，不按页面、操作类型、屏幕方向或控件高度另外设置圆角。

| 变量 / 形态 | 值 | 适用范围 |
| --- | --- | --- |
| `--control-radius` | `12px` | 普通、主要、危险和图标按钮，输入框、搜索框、下拉选择、会话标签、快捷键、补全按钮、导航选中指示块、项目图标底块、扫码预览、命令栏与字号步进器 |
| `--group-radius` | `var(--control-radius)` | 首页卡片、分组列表、设置分组、对话框，始终跟随控件基准 |
| 底部弹层 | `var(--group-radius) var(--group-radius) 0 0` | 顶部两角为 12px；底部贴屏保持直角 |
| 左侧会话抽屉 | `0 var(--group-radius) var(--group-radius) 0` | 贴左屏幕边缘，右侧两角为 12px |
| 分组内的行 | `0` | 项目、连接、会话行的外轮廓由 `.rows` 统一裁切，行之间用分隔线，不逐行增加圆角 |
| 圆形元素 | `50%` | 状态点、连接头像、步骤编号、修饰键锁定指示点；不用于矩形或图标按钮 |
| 弹层拖动条 | `2px` | 4px 高的装饰条，保持半圆端点 |

- 通过语义变量设置 `border-radius`，不在组件或媒体查询中重复写 `10px`、`18px`、`24px` 等独立值，也不使用按按钮高度计算的胶囊圆角。
- 图标按钮与文字按钮使用相同圆角；发送、键盘、图片和字号增减按钮同样遵守。
- 当前、按下、聚焦、禁用状态只改变颜色、边框或透明度，不改变外轮廓。焦点轮廓跟随控件圆角。
- 分组外框负责裁切背景；底部弹层贴屏的边与内部列表行保留直角。终端输出区和整页背景不额外包圆角卡片。
- Android 系统文件选择器、输入法、权限对话框、系统栏及应用图标由系统或各自资源管理，不覆盖为 WebView 控件圆角。

## 颜色与状态

沿用石墨底色和青绿强调色，使用 `app.css` 中的变量。

| 用途 | 变量 | 当前值 |
| --- | --- | --- |
| 页面 / 终端背景 | `--paper` / `--console` | `#111419` / `#101317` |
| 分组 / 搜索 / 浮起表面 | `--surface` / `--surface-high` / `--raised` | `#1a2027` / `#1f262e` / `#262e38` |
| 正文 / 辅助文字 | `--ink` / `--muted` | `#edf2f6` / `#a2aeba` |
| 边框 / 分隔线 | `--line` / `--divider` | `#303944` / `#262e37` |
| 主操作 / 选中背景 | `--accent` / `--accent-surface` | `#68dfc6` / `#193a35` |
| 错误 / 危险操作 | `--error` | `#ff9d8c` |

在线、检查中、离线状态始终有文字说明，不能只依赖颜色。选中导航只在图标后显示圆角背景，不给整块导航项加边框。图标复用现有 Lucide SVG。

会话标题中的 CLI 点阵动画统一显示为独立的圆环加载图标，配「运行中」文字；每个会话独立显示，手动名称不覆盖程序状态。侧栏打开且应用在前台时串行刷新所有会话元数据，关闭或后台时暂停；刷新保留行节点、焦点和动画连续性。退出后停止动画，减少动画偏好下保留静态圆环和文字。运行状态来自程序标题，不以终端进程存在或手机是否选中判断。

## 布局与输入

- 导航固定为「对话 / 项目 / 连接」，默认进入对话。终端首页从对话页「终端会话」、项目行和对话设置进入，返回键回到对话。页面采用单列内容，项目和连接使用分组列表。
- 手机终端与对话的 Agent 进程统一在 24 小时无输入也无输出后自动结束；会话侧栏每行下方、对话管理弹层与对话设置中显示「空闲 N 小时，M 小时后自动结束 / 自动暂停」，已经过的时长向下取整，剩余时长向上取整。对话「管理」弹层逐行提供「暂停 / 删除」，并有「暂停全部空闲 Agent」「删除已暂停的对话」批量操作，删除需确认；执行中或待审批的对话按钮禁用。
- 对话列表沿用分组行：Agent 头像（Claude / Codex / OpenCode 首字母与固定色相）、标题、Agent · 项目 · 时间、最近一条消息与状态标签；待审批与执行中排在前面。顶部额度条每家显示占用最高的窗口，进度条为 4px 高的装饰条、2px 圆角。
- 对话页：用户消息靠右为强调底色气泡；Agent 回复整宽 Markdown，不包气泡；思考、工具调用为单行可展开卡片，状态用文字（进行中 / 完成 / 失败 / 已拒绝），不只靠颜色；审批卡片用琥珀色边框，按钮按「允许（主要）/ 次要 / 拒绝（危险色）」排列且至少 44px。处理后的审批只保留结论，改动由工具卡片展示。底部依次是安全 / 模型标签与用量、状态行、附件、输入栏；执行中发送按钮变为危险色「停止」。「完全访问」标签与选项使用琥珀色提示，切换需确认。
- 项目页的项目行点按仍打开终端，行尾 48px 对话按钮打开 Agent 选择弹层；Windows 远端项目在弹层中禁用对话并说明原因，Linux / macOS 远端可以对话。
- 终端顶部只显示当前会话名称与项目来源，不放横向会话标签。左侧抽屉按项目列出会话，选中后收起；每行显示名称、编号和状态，并提供至少 44px 的重命名按钮。手动名称优先于程序标题，允许恢复自动命名。新建、结束当前与全部等会话操作集中在抽屉；终端设置沿用原弹层，横屏通过底部菜单进入同一抽屉。
- 首页「最近打开」最多显示 10 个项目，按实际最近打开时间排序；页面整体纵向滚动，底部导航固定，不为项目分组增加嵌套滚动区域。
- 项目名、来源、地址和路径按信息层级显示；长文本可换行或截断，不能挤出屏幕。项目搜索吸顶，空结果保留清除搜索入口。
- 普通操作沿用至少 44px 的触控高度；终端快捷键沿用现有尺寸，不为圆角修改缩小触控区。
- 终端占剩余高度，命令栏、快捷键和补全入口共用控件圆角。字号仅在手机保存，范围为 11–20px。
- 终端底部状态行显示纯文字「电脑 32 ms」，首页电脑状态复用同一结果；不添加彩色徽章或独立操作按钮。小于 1ms 显示 `<1 ms`，不可用显示 `电脑 --`；320px 窄屏隐藏网格尺寸，把空间留给状态、延迟和操作。连接详情解释手机到电脑的认证请求往返范围和最近测量时间，不混用电脑到远端的延迟。
- 延迟使用原生单调时钟测量网络请求，不统计长轮询等待、JS 回调或原生任务排队；与输入和输出请求使用独立探测队列。终端前台每 10 秒测量，工作台每 30 秒测量；后台暂停，前台立即补测，每次仅一个探测在途。同一电脑切换终端复用数值，换电脑、端口、证书或重新配对时清除旧值并丢弃迟到结果。失败或三个采样周期后结果过期显示 `--`，不改变业务连接状态；旧电脑不支持时停止周期探测，并在详情说明更新电脑端。
- 实时终端文字长按约 500ms 进入选字，用两个至少 44px 的手柄调整范围，支持跨行、中文宽字符和贴边滚动；浮动工具栏提供「复制 / 全选 / 取消」，写入手机剪贴板。手势进入选区后停止原滚动与惯性，不向 TUI 发送输入。历史文本沿用系统选字；已有选区时不因滑到页底自动退出历史。返回键先取消实时选区，网格尺寸变化和切换会话时清理选区、计时器和手柄。
- 接回终端先显示最新快照，历史随滑动分页加载，不添加查看历史按钮或图标。历史页保留原可见行和阅读锚点，滑回底部自动回到实时画面；保留原有「回到最新」。触摸逐帧合并并提供减速惯性，新手势立即停止旧惯性；历史区采用原生滚动，实体鼠标保留 TUI 行为。全屏程序（备用屏或开启鼠标上报）默认不把触摸发给程序：上滑只打开手机端只读历史，其余竖滑吞掉；点按后 WebView 补发的兼容鼠标事件在容器捕获阶段拦截，只聚焦终端。设置「全屏程序中的触摸 → 发给程序」恢复滑动滚轮与点按点击。
- 常用快捷键默认单行，按使用频率排序并保持至少 44px 触控区：Esc、Tab、Ctrl+C、⇧Tab、↑、↓、⌫、/命令、←、→；宽度不足时横向滑动，「更多」固定在右端。@引用、换行、Ctrl / Alt、行首行尾、翻页及符号键放在更多弹层，不再单独增加技能和补全按钮行。横屏可折叠并保留展开入口；各视口继续使用同一组圆角变量。
- 命令输入框不显示「手机草稿」悬浮标签；实时输入通过整框强调色、键盘按钮选中态和占位文字明确表达。框内上方同一时间只显示一项短状态：图片上传进度 > 待处理的提交状态 > 补全提示 > 已接收 ✓；无状态时不占行，「已接收」约 4 秒后收成 ✓ 仍可点开查看。状态不压边框和发送按钮。键盘、图片与发送按钮对齐并保留至少 44px 触控区；图片按钮在键盘按钮旁。选图后显示「图片上传中…」，插入后短暂显示「✓ 图片已插入」，草稿提交后不再保留图片提示。编辑目标按会话记住，不能由瞬间焦点或键盘显隐推断。退格、左右移动和更多中的文本编辑跟随目标；清空草稿仅编辑本地。实时退格发送 Backspace，不能使用 Ctrl+D；长按只连续退格，不能变成清空。切换目标、会话、折叠、离开页面及组词时取消连发。Tab / ⇧Tab 保留实际键名，不能统一标为补全或某种 AI 模式。
- 终端横屏自动沉浸，隐藏系统栏与应用顶栏；转回竖屏或离开终端自动恢复，不提供手动全屏按钮。原生屏幕方向与键盘缩小的 WebView 视口分开判断；返回键先关闭弹层、选区或历史，再离开终端。
- 图片按钮固定在输入框内，折叠快捷键后仍可使用，直接打开支持多选的系统选择器。逐张读取、上传并插入草稿，显示当前张数；中途失败保留已插入图片，重新选择剩余图片，不自动重发。切换会话时停止余下上传并忽略迟到结果。压缩等级放在「终端设置」，自动保存并沿用。HEIC / HEIF 由系统解码后转换，能力受手机系统支持限制。
- 终端行列按输出区域扣除内边距后的可用尺寸计算，底部保留 8px 间距；折叠、展开、旋转和键盘改变高度后重新适配，最后一行不能落在工具栏后面。
- 命令栏支持中文组词、粘贴和每会话草稿；空命令发送回车，组词期间不提交。候选与补全由终端程序提供。
- 「更多 → 清除输入」始终作用于终端当前行；识别当前输入行的 Windows PowerShell 提示符时发送 Ctrl+Home、Ctrl+End，其他程序发送 Ctrl+E、Ctrl+U。识别覆盖视觉折行，但不扫描历史输出，也不按项目来源猜前台程序。保留手机命令栏草稿，不发送回车或中断信号；实际编辑由终端程序的按键绑定处理。「清空草稿」仍只编辑本地，在实时输入模式下禁用。
- 终端设置中的触摸模式用带短说明的单选行，避免系统下拉弹窗把长选项挤成多行。快捷键按文字自然宽度分配空间，Ctrl+C 等标签不得挤出按钮边界，整行保留横向滚动。
- 「发送并直接 Enter」等待文字输入请求成功后，间隔 250ms 再单独发送回车；同次提交在输入队列中连续执行，后续按键不能插队。文字发送失败、离开或切换会话不补发回车，回执显示结果未知。斜杠草稿的发送按钮随此设置显示「发送」或「候选」。
- 底部状态行保留「…」菜单，横屏隐藏顶栏后仍能进入会话、设置、新建与返回。展开编辑页复用同一份草稿，回车只换行；保存与提交记录按电脑、项目和终端隔离，结果未知只能手动恢复，不自动重发。
- 提交回执只表达终端输入的发送状态，与 Agent 的执行、完成及权限状态分开。较新的草稿不受旧回执影响；存储失败要明确提示原文未能保存在手机。
- 输出阅读为独立的只读快照，提供搜索、匹配跳转、可选折行、diff 行颜色与网页链接。新输出只提示刷新，不能替换正在阅读的快照；搜索范围必须明确。终端设置支持真实固定列宽与横向滚动，不以 CSS 拉伸字符。
- 会话列表始终使用可收起的左侧抽屉；终端设置和连接详情在窄屏使用底部弹层、宽屏使用居中对话框。操作按钮、输入框、内容容器使用同一圆角基准。
- 安全区域、挖孔和软键盘避让沿用 `--safe-*`。终端工具区左右固定保留 8px，不能把屏幕圆角半径用于整块工具区的水平内边距；底部通过 `--corner-bottom-inset` 保留圆角所需的最小净空，扣除原生系统栏或键盘已避让的高度。工作台导航继续沿用 `--corner-inset`，不靠放大界面圆角避让。

## 验收

使用真实 `web/` 资产的浏览器 fixture：运行 `pnpm test:web`，访问 `http://127.0.0.1:38439/mobile-android/`。Linux 使用 `agent-browser`，Windows / macOS 使用 Ego；具体流程见 [Web UI 验收](../../docs/web-ui-testing.md)。

检查首页、项目、连接、配对、终端、会话弹层和居中对话框的圆角一致性，并覆盖 320px 窄屏、390px 竖屏、横屏及软键盘高度。保留截图到 `.dev/`，核对分组裁切、弹层顶角、按钮聚焦和内容溢出。

浏览器验收覆盖 WebView 样式与内存 RPC；Android 系统栏、输入法、系统选择器、原生桥和实际网络连接需要另行真机验证。
