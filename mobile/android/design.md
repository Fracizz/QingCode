# QingCode Android 设计规范

本规范适用于本目录中的 Android 应用：`MainActivity.java`、`res/` 和 `web/`。WebView 界面样式以 `web/app.css` 为准；桌面端共用的品牌与交互原则见 [仓库设计规范](../../DESIGN.md)。新增和修改页面时沿用现有组件、颜色与圆角变量。

## 圆角

矩形控件和容器统一使用 **12 CSS px**，不按页面、操作类型、屏幕方向或控件高度另外设置圆角。

| 变量 / 形态 | 值 | 适用范围 |
| --- | --- | --- |
| `--control-radius` | `12px` | 普通、主要、危险和图标按钮，输入框、搜索框、下拉选择、会话标签、快捷键、补全按钮、导航选中指示块、项目图标底块、扫码预览、命令栏与字号步进器 |
| `--group-radius` | `var(--control-radius)` | 首页卡片、分组列表、设置分组、对话框，始终跟随控件基准 |
| 底部弹层 | `var(--group-radius) var(--group-radius) 0 0` | 顶部两角为 12px；底部贴屏保持直角 |
| 左侧会话抽屉 | `0 var(--group-radius) var(--group-radius) 0` | 贴左屏幕边缘，右侧两角为 12px |
| 分组内的行 | `0` | 项目、连接、会话行的外轮廓由 `.rows` 统一裁切，行之间用分隔线，不逐行增加圆角 |
| 圆形元素 | `50%` | 状态点、连接头像、步骤编号、修饰键锁定指示点；不用于矩形或图标按钮 |
| 弹层拖动条 | `2px` | 4px 高的装饰条，保持半圆端点 |

- 通过语义变量设置 `border-radius`，不在组件或媒体查询中重复写 `10px`、`18px`、`24px` 等独立值，也不使用按按钮高度计算的胶囊圆角。
- 图标按钮与文字按钮使用相同圆角；发送、键盘、图片和字号增减按钮同样遵守。
- 当前、按下、聚焦、禁用状态只改变颜色、边框或透明度，不改变外轮廓。焦点轮廓跟随控件圆角。
- 分组外框负责裁切背景；底部弹层贴屏的边与内部列表行保留直角。终端输出区和整页背景不额外包圆角卡片。
- Android 系统文件选择器、输入法、权限对话框、系统栏及应用图标由系统或各自资源管理，不覆盖为 WebView 控件圆角。

## 颜色与状态

沿用石墨底色和青绿强调色，使用 `app.css` 中的变量。

| 用途 | 变量 | 当前值 |
| --- | --- | --- |
| 页面 / 终端背景 | `--paper` / `--console` | `#111419` / `#101317` |
| 分组 / 搜索 / 浮起表面 | `--surface` / `--surface-high` / `--raised` | `#1a2027` / `#1f262e` / `#262e38` |
| 正文 / 辅助文字 | `--ink` / `--muted` | `#edf2f6` / `#a2aeba` |
| 边框 / 分隔线 | `--line` / `--divider` | `#303944` / `#262e37` |
| 主操作 / 选中背景 | `--accent` / `--accent-surface` | `#68dfc6` / `#193a35` |
| 错误 / 危险操作 | `--error` | `#ff9d8c` |

在线、检查中、离线状态始终有文字说明，不能只依赖颜色。选中导航只在图标后显示圆角背景，不给整块导航项加边框。图标复用现有 Lucide SVG。

会话标题中的 CLI 点阵动画统一显示为独立的圆环加载图标，配「运行中」文字；每个会话独立显示，手动名称不覆盖程序状态。侧栏打开且应用在前台时串行刷新所有会话元数据，关闭或后台时暂停；刷新保留行节点、焦点和动画连续性。退出后停止动画，减少动画偏好下保留静态圆环和文字。运行状态来自程序标题，不以终端进程存在或手机是否选中判断。

## 布局与输入

- 导航固定为「终端 / 项目 / 连接」。页面采用单列内容，首页突出继续终端与当前电脑状态，项目和连接使用分组列表。
- 手机终端在 24 小时无输入也无输出后自动结束；会话侧栏每行下方显示「空闲 N 小时，M 小时后自动结束」，已经过的时长向下取整，剩余时长向上取整。
- 终端顶部只显示当前会话名称与项目来源，不放横向会话标签。左侧抽屉标题显示数量，新建终端置顶；列表使用独立的 12px 圆角状态行，不给空白区域铺大块底色。每行名称最多两行，保留编号和运行状态，并提供至少 44px 的更多操作、关闭按钮；长按或更多菜单支持重命名与本地置顶。手动名称优先于程序标题，允许恢复自动命名。关闭前确认具体会话，关闭其他会话不切换当前终端和草稿；关闭当前项接回剩余会话，最后一项关闭后回到工作台。底部集中返回工作台、终端设置及「关闭全部会话」，批量操作只影响确认的当前项目会话，失败保留并支持重试。终端设置沿用原弹层，横屏通过底部菜单进入同一抽屉。
- 会话纵览（`sessionOverview.js`）由工作台首页与会话抽屉共用：搜索框独占一行，下方为「全部 / 未结束 / 已结束」筛选（带数量），再下一行左侧「运行中优先」勾选、右侧「管理」（矮屏并到搜索框右侧）；首页会话不超过 4 个且未搜索 / 筛选时收起搜索与筛选；组头显示项目名、来源、「当前项目」或「电脑端已移除」及该项目会话总数；行内复用会话行样式（名称、编号、状态、上次使用、空闲时长、其他设备的「来自 设备名」）和 44px 关闭按钮，不提供置顶与重命名。首页「全部会话」默认显示，可在「设置 → 工作台」关闭，位于「继续终端」与「最近打开」之间，随整页滚动、不做嵌套滚动区，先显示 8 个并提供「展开全部 / 收起」，没有会话时隐藏。抽屉顶部用分段控件切换「本项目 / 全部」，「全部」时隐藏新建终端与「关闭全部会话」，列表独立滚动；矮屏（高度 ≤450px）下搜索、筛选与分组一起滚动，底部操作并成一行，至少完整显示一行会话。「管理」进入多选：行首显示勾选框、隐藏单行关闭按钮，点整行切换选择；工具条显示「已选 N / 全选 N（取消全选）/ 选已结束 / 关闭所选」，多选时不截断列表；关闭后若已无选中项自动退出多选，离开首页也退出。
- 首页「最近打开」最多显示 10 个项目，按实际最近打开时间排序；页面整体纵向滚动，底部导航固定，不为项目分组增加嵌套滚动区域。
- 项目名、来源、地址和路径按信息层级显示；长文本可换行或截断，不能挤出屏幕。项目搜索吸顶，空结果保留清除搜索入口。
- 普通操作沿用至少 44px 的触控高度；终端快捷键沿用现有尺寸，不为圆角修改缩小触控区。
- 终端占剩余高度，命令栏、快捷键和补全入口共用控件圆角。字号仅在手机保存，范围为 11–20px。
- 终端底部状态行显示纯文字「电脑 32 ms」，首页电脑状态复用同一结果；不添加彩色徽章或独立操作按钮。小于 1ms 显示 `<1 ms`，不可用显示 `电脑 --`；320px 窄屏隐藏网格尺寸，把空间留给状态、延迟和操作。连接详情解释手机到电脑的认证请求往返范围和最近测量时间，不混用电脑到远端的延迟。
- 延迟使用原生单调时钟测量网络请求，不统计长轮询等待、JS 回调或原生任务排队；与输入和输出请求使用独立探测队列。终端前台每 10 秒测量，工作台每 30 秒测量；后台暂停，前台立即补测，每次仅一个探测在途。同一电脑切换终端复用数值，换电脑、端口、证书或重新配对时清除旧值并丢弃迟到结果。失败或三个采样周期后结果过期显示 `--`，不改变业务连接状态；旧电脑不支持时停止周期探测，并在详情说明更新电脑端。
- 实时终端文字长按约 500ms 进入选字，用两个至少 44px 的手柄调整范围，支持跨行、中文宽字符和贴边滚动；浮动工具栏提供「复制 / 添加到对话 / 全选 / 取消」，复制写入手机剪贴板，成功后自动退出选区并提示「已复制」（失败时保留选区）；「添加到对话」与电脑端一致，仅在程序开启括号粘贴（Claude Code 等 AI CLI）且终端可写时显示，把选区转成 Markdown 引用粘贴到输入行，不自动发送。手势进入选区后停止原滚动与惯性，不向 TUI 发送输入。历史文本沿用系统选字；已有选区时不因滑到页底自动退出历史。返回键先取消实时选区，网格尺寸变化和切换会话时清理选区、计时器和手柄。
- 接回终端先显示最新快照，历史随滑动分页加载，不添加查看历史按钮或图标。历史页保留原可见行和阅读锚点，滑回底部自动回到实时画面；保留原有「回到最新」。触摸逐帧合并并提供减速惯性，新手势立即停止旧惯性；历史区采用原生滚动，实体鼠标保留 TUI 行为。全屏程序（备用屏或开启鼠标上报）默认不把触摸发给程序：上下两个方向均可进入只读历史，进入的整次手势继续向历史移动，不能刚打开就退出；没有更早缓存时保留当前画面并明确提示。电脑端对备用屏被重绘覆盖的画面每秒至多记录一次纯文本，标记「全屏画面历史」，与普通历史共用 1 MiB / 5000 行上限；不记录不变画面、控制序列或程序尚未显示的内容。普通终端沿用自然滚动。点按后 WebView 补发的兼容鼠标事件在容器捕获阶段拦截，只聚焦终端。设置「全屏程序中的触摸 → 发给程序」恢复滑动滚轮与点按点击。
- 快捷键栏可在「终端设置 → 快捷键栏」调整：每行一个键，勾选显示；长按行（约 320ms，震动反馈）拖动排序，被拖行抬起、其余行让位，按住期间滑动仍是滚动；44px 上移 / 下移按钮保留用于无障碍与微调，「恢复默认」回到默认顺序；只保存在手机。隐藏的键移入「更多」顶部「已从快捷键栏隐藏」分组，不会丢失；「更多」按钮始终固定在栏最右侧。「更多」弹层中的按键使用 `--paper` 底色，与弹层表面区分。
- 字号除设置中的 A− / A+ 外，可在终端输出区双指缩放：两指距离变化超过约 12px 才开始，按比例取整并限制在 11–20px，输出区顶部居中显示「字号 N px」，松手后保存；双指手势在捕获阶段截停，不触发单指滚动、长按选字或发给程序。
- 实时终端的 http / https 链接通过 xterm 链接识别（按单元格映射，支持中文宽字符与自动折行），点按打开底部菜单「在浏览器打开 / 复制链接」，不直接跳转。电脑本地地址（localhost、127.x、0.0.0.0、::1）在本机与 WSL 项目中换成电脑局域网地址并说明需监听局域网；SSH 项目只允许复制。全屏程序拦截鼠标时按触点坐标识别链接，不发鼠标上报。
- 常用快捷键默认单行，按使用频率排序并保持至少 44px 触控区：Esc、Tab、Ctrl+C、⇧Tab、↑、↓、⌫、/命令、←、→；宽度不足时横向滑动，「更多」固定在右端。@引用、换行、Ctrl / Alt、行首行尾、翻页及符号键放在更多弹层，不再单独增加技能和补全按钮行。横屏可折叠并保留展开入口；各视口继续使用同一组圆角变量。
- 命令输入框不显示「手机草稿」悬浮标签；实时输入通过整框强调色、键盘按钮选中态和占位文字明确表达。框内上方同一时间只显示一项短状态：图片上传进度 > 待处理的提交状态 > 补全提示 > 已接收；无状态时不占行。「✓ 电脑已接收」只对本次界面上看着发出的提交显示约 4 秒，随后整行消失，不留勾号占位，重新进入终端不回放旧回执；发送中、结果未知、保存失败持续显示。状态行在延迟前常驻纯文字「草稿 / 直发」（直发用强调色，不做徽章），首次进入终端在快捷键上方显示一次说明，「知道了」或主动切换模式后不再出现。输入框横向拖动移动光标：越过阈值且明显横向才接管，草稿每约 10px 移动一个字素，直发每约 14px 发送一次 ← / →；拖动中命令栏改为强调色虚线边框，竖向拖动和组词不受影响，拖动后不切换编辑目标。状态不压边框和发送按钮。键盘、图片与发送按钮对齐并保留至少 44px 触控区；图片按钮在键盘按钮旁。选图后显示「图片上传中…」，插入后短暂显示「✓ 图片已插入」，草稿提交后不再保留图片提示。编辑目标按会话记住，不能由瞬间焦点或键盘显隐推断。退格、左右移动和更多中的文本编辑跟随目标；清空草稿仅编辑本地。实时退格发送 Backspace，不能使用 Ctrl+D；长按只连续退格，不能变成清空。切换目标、会话、折叠、离开页面及组词时取消连发。Tab / ⇧Tab 保留实际键名，不能统一标为补全或某种 AI 模式。
- 终端横屏自动沉浸，隐藏系统状态栏与导航栏，保留应用顶栏；转回竖屏或离开终端自动恢复，不提供手动全屏按钮。原生屏幕方向与键盘缩小的 WebView 视口分开判断；返回键先关闭弹层、选区或历史，再离开终端。
- 图片按钮固定在输入框内，折叠快捷键后仍可使用，直接打开支持多选的系统选择器。逐张读取、上传并插入草稿，显示当前张数；中途失败保留已插入图片，重新选择剩余图片，不自动重发。切换会话时停止余下上传并忽略迟到结果。压缩等级放在「终端设置」，自动保存并沿用。HEIC / HEIF 由系统解码后转换，能力受手机系统支持限制。
- 终端行列按输出区域扣除内边距后的可用尺寸计算，底部保留 8px 间距；折叠、展开、旋转和键盘改变高度后重新适配，最后一行不能落在工具栏后面。
- 命令栏支持中文组词、粘贴和每会话草稿；空命令发送回车，组词期间不提交。候选与补全由终端程序提供。
- 「更多 → 清除输入」始终作用于终端当前行；识别当前输入行的 Windows PowerShell 提示符时发送 Ctrl+Home、Ctrl+End，其他程序发送 Ctrl+E、Ctrl+U。识别覆盖视觉折行，但不扫描历史输出，也不按项目来源猜前台程序。保留手机命令栏草稿，不发送回车或中断信号；实际编辑由终端程序的按键绑定处理。「清空草稿」仍只编辑本地，在实时输入模式下禁用。
- 终端设置中的触摸模式用带短说明的单选行，避免系统下拉弹窗把长选项挤成多行。快捷键按文字自然宽度分配空间，Ctrl+C 按钮精简显示为 `^C`，无障碍名称保留「发送 Ctrl+C」；标签不得挤出按钮边界，整行保留横向滚动。
- 「发送并直接 Enter」等待文字输入请求成功后，间隔 250ms 再单独发送回车；同次提交在输入队列中连续执行，后续按键不能插队。文字发送失败、离开或切换会话不补发回车，回执显示结果未知。斜杠草稿的发送按钮随此设置显示「发送」或「候选」。
- 底部状态行保留「…」菜单，横屏沉浸时同样可进入会话、设置、新建与返回。展开编辑页复用同一份草稿，回车只换行；保存与提交记录按电脑、项目和终端隔离，结果未知只能手动恢复，不自动重发。
- 提交回执只表达终端输入的发送状态，与 Agent 的执行、完成及权限状态分开。较新的草稿不受旧回执影响；存储失败要明确提示原文未能保存在手机。
- 输出阅读为独立的只读快照，提供搜索、匹配跳转、可选折行、diff 行颜色与网页链接。新输出只提示刷新，不能替换正在阅读的快照；搜索范围必须明确。终端设置支持真实固定列宽与横向滚动，不以 CSS 拉伸字符。
- 下拉选项不使用系统原生样式：触发按钮沿用输入控件的边框与圆角，点开后是共用的 `select-dialog` 选择面板（窄屏贴底弹层、宽屏居中），当前项用强调色底与对勾标出，「主文案 · 说明」拆成两行，点选后立即生效并关闭，返回键和点遮罩只取消。新增下拉一律走 `selectMenu.js`，不要自行实现。
- 关闭单个会话时抽屉不关闭、列表不变暗：确认后只收起对应行，关闭的是当前会话时在抽屉下方切换终端。
- 通用设置（语言、应用更新、图片压缩、发送按键、后台提醒、硬件加速）集中在全屏「设置」页：工作台顶栏齿轮或「终端设置 → 更多设置」打开，叠在当前界面上不打断会话，返回键逐层关闭。底部导航不增加第四项；列宽、触摸、字号和快捷键栏留在终端设置就地调整。
- 手机上会话列表使用可收起的左侧抽屉；平板宽屏（窗口宽 ≥840px 且设备最短边 ≥600px，对应 sw600dp）在终端页可展开为双栏：同一侧栏以非模态方式常驻左侧 300px。双栏默认收起，左上角侧栏按钮切换展开 / 收起（展开时按钮高亮），选择保存在本机；「… → 会话列表」只展开。常驻时隐藏侧栏内关闭按钮，切换、新建会话和打开设置不再收起，返回键直接离开终端，元数据每 3 秒刷新，收起后停止刷新。横屏手机和窄分屏窗口仍用抽屉；按设备最短边而非视口高度判断，弹出输入法不切换布局。终端设置和连接详情在窄屏使用底部弹层、宽屏使用居中对话框。操作按钮、输入框、内容容器使用同一圆角基准。
- 接入实体键盘（原生 `qingHardKeyboard`）时默认收起快捷键栏；连接期间手动展开只在本次有效、不写入偏好，拔出后恢复原偏好。
- 安全区域、挖孔和软键盘避让沿用 `--safe-*`。终端工具区左右固定保留 8px，不能把屏幕圆角半径用于整块工具区的水平内边距；底部通过 `--corner-bottom-inset` 保留圆角所需的最小净空，扣除原生系统栏或键盘已避让的高度。工作台导航继续沿用 `--corner-inset`，不靠放大界面圆角避让。

## 验收

使用真实 `web/` 资产的浏览器 fixture：运行 `pnpm test:web`，访问 `http://127.0.0.1:38439/mobile-android/`。Linux 使用 `agent-browser`，Windows / macOS 使用 Ego；具体流程见 [Web UI 验收](../../docs/web-ui-testing.md)。

检查首页、项目、连接、配对、终端、会话弹层和居中对话框的圆角一致性，并覆盖 320px 窄屏、390px 竖屏、横屏及软键盘高度。保留截图到 `.dev/`，核对分组裁切、弹层顶角、按钮聚焦和内容溢出。

浏览器验收覆盖 WebView 样式与内存 RPC；Android 系统栏、输入法、系统选择器、原生桥和实际网络连接需要另行真机验证。
