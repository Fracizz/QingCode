暂无已配对电脑

在电脑端「设置 → 功能 → Android 移动连接」启用后，点「添加」扫描二维码。

命令栏可编辑中文 · 空白发送为回车

添加连接

打开电脑端「设置 → 功能 → Android 移动连接」，用手机扫描其中的二维码。

已从配对链接读取地址和证书指纹，连接时自动核对。

核对电脑身份

请逐位核对电脑端显示的 SHA-256 指纹。

连接详情

电脑端切换端口后，在这里改为新端口即可，无需重新配对。

扫描配对二维码

将电脑端二维码完整放在画面中央，稍等相机对焦；若模糊，请稍微拉远手机。
