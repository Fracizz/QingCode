扫描配对二维码

更多按键

    
编辑目标：手机草稿

    

      
      
      
      
      
      
      
      
      
      
      
      
      
      
      
    

    
「清除输入」清除终端当前行尚未提交的文字；「清空草稿」只清手机命令栏。按键由当前程序处理。Esc 取消或中断，不删除文字；Ctrl+C 也可能退出程序。

    

  

  
    
会话

    

    

    

    
更新电脑端后可重命名会话。

    

      
      
      
      
      
    

  

  
    

    
会话操作

    

      
      
      
    

    
置顶只保存在这台手机上，不改变电脑端终端顺序。

    

  

  
    

      
重命名会话

      
      
      
手动名称优先。留空保存后恢复跟随程序标题。

      

      

    

  

  
    

    
终端设置

    
    
    
固定列宽时可横向滚动，旋转和键盘弹出只改变可见高度。

    

      全屏程序中的触摸
      
      
    

    
Codex、OpenCode 等会接管鼠标。默认手指滑动只打开手机端只读历史，点按不发点击；需要用手指滚动程序界面时再改为「发给程序」。实体鼠标不受影响。

    
终端字号
仅调整手机显示

    
    
    
自动保存，下次发图直接使用。原图保留 PNG / JPEG 文件；HEIC / HEIF 需要系统支持解码，原图模式保留分辨率并转换格式。单张上传最大 8 MB，超出时请选择压缩。

    
    
    
「发送并直接 Enter」等待文字发送成功后再单独发送回车；/命令也会提交。是否执行由当前终端程序决定。

    

  

  
    
新建会话

    

    

    
选项来自电脑端「设置 → 终端 → 终端配置」；启动命令在当前项目环境（本机、WSL 或远端）中执行。

    

  

  
    
图片未能上传

    
可重新选择未上传的图片；压缩等级在终端设置中调整。已插入的图片会保留在草稿中。

    

    

  

  
    

    
终端操作

    

      
      
      
      
      
      
    

    

  
  
    
编辑指令

    

    
    
草稿保存在手机，输入法回车只换行。图片上传后的路径会加入指令。

    

  
  
    
提交与草稿

    
“电脑已接收”表示终端收到输入。结果未知时先核对输出，内容不会自动重发。

    

    
    

    

  
  
    
输出阅读

    

    

    

    
只读快照，最多保留末尾 60 万字符。实时输出不会改变阅读位置；刷新后才更新。

    

  
  
    

    
新对话

    

    
项目

    
    
没有可用于对话的项目；Windows 远端项目暂只支持终端。

    
权限

    

    

    
完全访问：Agent 不再请求手机确认，会直接编辑文件和运行命令。

    
    

    

  

  
    

    
对话设置

    

    

    

      
      
      
    

    
Claude 的推理强度在 Agent 空闲时重启生效，会话上下文自动恢复。

    

    

      
      
      
      
    

    

  

  
    

    

    

    

    
没有匹配的选项

    

  

  
    

    
默认安全选项

    
新对话按这里的选项启动，保存在当前电脑。选择「完全访问」时，Agent 不再向手机请求审批。

    

    

    

    

  

  
    

    
使用额度

    
读取电脑上已登录的 Claude 与 Codex 账号额度；OpenCode 按所选模型的提供方计费。

    

    

    

  

  
    

    

    

      
      
      
      
    

    
Windows 远端项目暂只支持终端；Linux / macOS 远端可以对话。

    

  

  
    

    
管理对话

    
Agent 进程 24 小时内既无输入也无输出时自动暂停（手机终端同样 24 小时后结束）。暂停只结束进程，对话保留，再次发送消息时恢复上下文。
