工作区

项目

设备管理

连接

选择要控制的 QingCode 电脑。

暂无已配对电脑

在电脑端「设置 → 功能 → Android 移动连接」启用后，点「添加」扫描二维码。

添加连接

在电脑端「设置 → 功能 → Android 移动连接」中扫描二维码，或粘贴复制的配对链接。

已从配对链接读取地址和证书指纹，连接时自动核对。

核对电脑身份

请逐位核对电脑端显示的 SHA-256 指纹。

连接详情

电脑端切换端口后，在这里改为新端口即可，无需重新配对。

扫描配对二维码

对准电脑端「Android 移动连接」中显示的二维码。
